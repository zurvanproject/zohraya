# مقایسهٔ هم‌شرایط API و دو روش بدون هزینهٔ اضافی API

طرح پیش از دیدن پیامدهای آزمون ثبت می‌شود. شش مسیر تازه: دو وضعیت normal و sleep، هرکدام با مدت‌های ۰٫۲، ۰٫۵ و ۱ ثانیه، در دو دور؛ جمعاً ۱۲ گذار موتور بدن نرم‌افزاری. این‌ها شش مسیر مرتبط از دو وضعیت مصنوعی‌اند، نه ۱۲ نمونهٔ مستقل و نه آزمون تجربهٔ ذهنی.

سه روش دقیقاً همان وضعیت مشاهده‌شده، ترجیح walk، مدت و تاریخچه را دریافت می‌کنند. چهار گذار اجراشدهٔ آزمایش قبلی نمونهٔ آموزشی مشترک‌اند؛ خروجی زبانی یا پیش‌بینی‌های آن مدل وارد دادهٔ آموزشی نمی‌شود. پس از پایان دور اول، شش رسید جدید به تاریخچهٔ مشترک افزوده می‌شود. نمونه‌های قبلی با مدت ۰٫۱ بوده‌اند؛ مدت‌های آزمون تازه‌اند. هیچ روش نتیجهٔ آینده، کد هسته یا پایگاه خصوصی وضعیت را برای پیش‌بینی دریافت نمی‌کند.

1. **ثابت فرض کردن وضعیت:** چهار عدد فعلی را برای آینده تکرار می‌کند و اقدام walk را پیش‌بینی می‌کند.
2. **یادآوری نزدیک‌ترین تجربه:** در همان fixture، کمترین مجموع اختلاف چهار شاخص قبل از اجرا را پیدا می‌کند؛ تساوی با تازه‌ترین تجربه شکسته می‌شود. تغییر مشاهده‌شدهٔ آن تجربه را به نسبت مدت زمان مقیاس می‌کند و به وضعیت فعلی می‌افزاید؛ اعداد به صفر تا یک محدود می‌شوند. اقدام همان تجربه را پیش‌بینی می‌کند. این روش با دریافت رسیدهای دور اول به‌روز می‌شود و هیچ فراخوانی API ندارد.
3. **API:** مدل و تنظیمات قبلی gpt-5.6-luna، reasoning=low؛ دو درخواست، هر دور یک بستهٔ شش‌تایی، بدون تکرار خودکار.

پیش‌بینی هر سه روش پیش از اجرای هر شش گذار همان دور ذخیره می‌شود. یک پیامد مشترک برای هر وضعیت، پاسخ هر سه را می‌سنجد؛ پیش‌بینی‌ها به بدن فرمان نمی‌دهند. سنجهٔ اصلی میانگین قدرمطلق خطا با وزن مساوی برای ۱۲ گذار و چهار شاخص صفر تا یک است. سنجهٔ دوم تعداد پیش‌بینی درست اقدام است. برتری عددی API فقط در صورت خطای میانگین کمتر از هر دو روش رایگان اعلام می‌شود؛ اقدام جدا گزارش می‌شود. هیچ روش پس از دیدن جواب‌ها برای این آزمون تنظیم نمی‌شود. همهٔ نتایج، حتی شکست، حفظ می‌شوند. تحلیل ریزتر بعدی باید پس‌نگر برچسب بخورد.

دو روش رایگان، همهٔ روش‌های ممکن رایگان یا خود ChatGPT بدون API را نمایندگی نمی‌کنند. هزینهٔ توسعه، پردازش محلی/CI و اشتراک موجود در مقایسهٔ هزینهٔ API محاسبه نمی‌شود. «رایگان» یعنی بدون هزینهٔ اضافی فراخوانی API برای پیش‌بینی. چهار نمونهٔ آموزشی مشترک از اجراهای قبلی بازیابی می‌شوند و هزینهٔ تاریخی آن‌ها در مجموع پروژه گزارش می‌شود.
