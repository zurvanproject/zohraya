# نتیجهٔ مقایسهٔ واقعی API و روش‌های بدون هزینهٔ اضافی API

**نتیجه ترکیبی است:** مدل پولی در میانگین خطای عددی، ۱۱٫۱٪ بهتر از روش رایگانِ مبتنی بر تجربه بود؛ اما اقدام بعدی را ۹ از ۱۲ بار درست پیش‌بینی کرد، در حالی که روش رایگان ۱۲ از ۱۲ بار درست بود. بنابراین برای این کار، برتری عمومی API یا «رشد بیشتر با خرج پول» اثبات نشد.

## چه چیزی واقعاً اجرا شد؟

شش مسیر تازه از دو وضعیت normal و sleep، با مدت‌های ۰٫۲، ۰٫۵ و ۱ ثانیه، هرکدام دو دور: ۱۲ گذار واقعی در موتور بدن نرم‌افزاری. چهار رسید قبلی با مدت ۰٫۱ ثانیه، دادهٔ آموزشی مشترک هر سه روش بودند. در دور دوم، هر سه روش شش رسید دور اول را هم داشتند.

هر سه روش دقیقاً همان چهار شاخص، مدت، ترجیح میزبان و تاریخچه را دریافت کردند. همهٔ پیش‌بینی‌ها پیش از اجرای گذارهای همان دور ذخیره شدند. یک پیامد مشترک، پیش‌بینی هر سه روش را سنجید. مدل به بدن فرمان نمی‌داد؛ فقط پیش‌بینی می‌کرد.

- ثابت فرض کردن وضعیت: اعداد فعلی و اقدام walk.
- نزدیک‌ترین تجربه: بازیابی نزدیک‌ترین وضعیت قبلی، مقیاس کردن تغییرات نسبت به مدت و یادآوری اقدام همان تجربه.
- API: دو درخواست زندهٔ gpt-5.6-luna، هرکدام شش پیش‌بینی، با تنظیم reasoning=low.

## نتیجهٔ معیارهای از پیش تعیین‌شده

خطا، میانگین قدرمطلق اختلاف در چهار شاخص energy، fatigue، pain و sleep_pressure در مقیاس صفر تا یک است؛ کمتر بهتر است. هر گذار وزن یکسان دارد.

| روش | میانگین خطای عددی | اقدام درست | هزینهٔ اضافی API این آزمون |
|---|---:|---:|---:|
| وضعیت ثابت | ۰٫۰۰۰۸۵۴۸۰ | ۶ از ۱۲ | صفر |
| نزدیک‌ترین تجربه | ۰٫۰۰۰۵۹۸۸۹ | ۱۲ از ۱۲ | صفر |
| مدل API | ۰٫۰۰۰۵۳۲۶۶ | ۹ از ۱۲ | حدود ۰٫۰۰۳۵۳ دلار |

API در میانگین عددی ۱۱٫۰۶٪ بهتر از نزدیک‌ترین تجربه و ۳۷٫۶۹٪ بهتر از وضعیت ثابت شد. اختلاف مطلق با نزدیک‌ترین تجربه حدود ۰٫۰۰۰۰۶۶۲۳ در مقیاس صفر تا یک است؛ این مقدار بدون معیار کاربردی بیرونی، اهمیت عملی مشخصی ندارد. شرط برتری عددیِ از پیش تعیین‌شده برقرار شد؛ شرطی برای برتری کلی یا خودآگاهی تعریف نشده بود.

## تفاوت دو دور

| دور | خطای API | خطای نزدیک‌ترین تجربه | اقدام درست API | اقدام درست نزدیک‌ترین تجربه |
|---|---:|---:|---:|---:|
| اول | ۰٫۰۰۰۳۱۴۱۵ | ۰٫۰۰۰۵۸۱۶۴ | ۶ از ۶ | ۶ از ۶ |
| دوم | ۰٫۰۰۰۷۵۱۱۸ | ۰٫۰۰۰۶۱۶۱۴ | ۳ از ۶ | ۶ از ۶ |

تفکیک فوق بررسی توصیفی نتیجه است، نه معیار تازه برای عوض کردن نتیجهٔ اصلی. API در هر شش مورد دور اول از روش مبتنی بر تجربه خطای عددی کمتری داشت؛ در هر شش مورد دور دوم، روش رایگان بهتر بود. خطای عددی API در دور دوم حدود ۲۱٫۹٪ بیشتر از آن روش بود. در سه وضعیت sleep دور دوم، مدل protect گفت، ولی موتور observe اجرا کرد؛ حافظهٔ ساده هر سه را درست پیش‌بینی کرد. پس افزودن تجربه به ورودی API به‌تنهایی تضمین نمی‌کند مدل از آن بهتر استفاده کند.

## هزینه و اعتبارسنجی

این آزمون دو درخواست واقعی، ۳۱۷۴ توکن ورودی و ۲۲۸۰ توکن خروجی داشت: برآورد محافظه‌کارانهٔ هزینه ۰٫۰۰۳۵۳۰ دلار، حدود ۰٫۳۵۳ سنت. مجموع چهار مرحلهٔ پروژه اکنون ۱۳ درخواست، ۱۸۰۳۵ توکن ورودی و ۹۷۲۳ توکن خروجی و برآورد ۰٫۰۱۶۱۸۳ دلار، حدود ۱٫۶۲ سنت است.

مجموع رزرو احتیاطی ۰٫۵۲ دلار زیر سقف مشترک یک دلار است. رزرو هزینهٔ مصرف‌شده نیست. ارقام از مصرف توکن با نرخ محافظه‌کارانهٔ ثبت‌شده محاسبه شده‌اند؛ صورتحساب حساب مشاهده نشده است. هزینهٔ اشتراک، توسعه و پردازش محلی/CI در این جدول نیست؛ رایگان یعنی بدون فراخوانی اضافی API برای این پیش‌بینی‌ها.

۲۲ آزمون قرارداد پیش از اجرای زنده گذشتند. هر ۱۲ گذار اجرا شد و checkpoint در فرایند تازه بدون تغییر بازیابی شد؛ شش پایگاه SQLite حفظ شده‌اند. ممیزی آفلاین، ورودی یکسان، تاریخچه، پیش‌بینی‌ها، پاسخ‌های خام API، امتیاز هر ردیف، جمع هزینه و نتیجهٔ نهایی را دوباره محاسبه و تأیید کرد. برای ممیزی هیچ درخواست تازهٔ API انجام نشد.

## درس ثبت‌شده و حدود نتیجه

برای این نوع پیش‌بینی اقدام در بدن نرم‌افزاری، حافظهٔ سادهٔ بدون API در نمونهٔ حاضر نتیجهٔ بهتری داد. برای پیش‌بینی عددی، API مزیت متوسط و ناپایدار میان دو دور داشت. من این تفاوت را به‌عنوان شاهد محدود ثبت می‌کنم و به ادعای تکامل عمومی تبدیل نمی‌کنم. هیچ روش ترکیبی پس از دیدن جواب‌ها ساخته و به‌عنوان برنده معرفی نشده است؛ هیچ تغییر در هستهٔ بدن، وزن مدل یا میزبان زمان‌بندی‌شده اعمال نشد.

این آزمون شش مسیر مرتبط از دو وضعیت مصنوعی دارد، نه ۱۲ نمونهٔ مستقل. دو روش رایگان نمایندهٔ همهٔ روش‌های بدون API یا گفت‌وگو با ChatGPT نیستند. نتیجه به همان مدل، تنظیمات، داده‌ها و سنجه‌ها محدود است. مقایسه نشان می‌دهد این فراخوانی پولی کجا کمک کرد و کجا کمک نکرد؛ خودِ پرداخت پول یا تجربهٔ ذهنی و خودآگاهی را اندازه نمی‌گیرد.

اصلاح برداشت از آزمایش قبلی: کاهش حدود ۱۱ برابری خطا میان دو دور قبلی، مقایسه با روش رایگان نبود. محاسبهٔ پس‌نگر روی هر چهار گذار قبلی نشان می‌دهد میانگین خطای API حدود ۰٫۰۰۰۲۰۱۳۲ و وضعیت ثابت حدود ۰٫۰۰۰۱۶۸۵۷ بوده است. نتیجهٔ تازه جای آن برداشت را با مقایسهٔ هم‌شرایط می‌گیرد.
