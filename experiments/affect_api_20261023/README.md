# نشست واقعی API با تمرکز بر تنظیم هیجان

کاربر اجرای واقعی با کلید موجود و سقف یک دلار را تأیید کرده است. این آزمایش
روی شاخهٔ اختصاصی اجرا می‌شود و به شرط غیبت ۲۴ساعتهٔ میزبان زمان‌بندی‌شده وابسته نیست.

هشت موقعیت آموزشیِ ساختگی، با چهار ترکیب حافظه و حالت عاطفی بررسی می‌شوند.
سپس مدل از بازخورد اندازه‌گیری‌شده یک سیاست تنظیم هیجان می‌نویسد. هشت موقعیت
کنارگذاشته‌شده با همان حافظه و حالت عاطفی، یک بار بدون این سیاست و یک بار با آن
به مدل داده می‌شوند. پاسخ‌های فارسی نیز ذخیره می‌شوند تا تفاوت رفتار دیده شود.
موقعیت‌ها ترس پس از شکست، اضطراب ناشی از سکوت، ناکامی، اعتمادبه‌نفس بیش‌ازحد،
همراهی با اندوه، کنجکاوی، خستگی و اختصاصی‌بودن حافظه را پوشش می‌دهند.

پاسخ مورد انتظار از قبل در کد ثبت می‌شود و وارد درخواست تصمیم نمی‌شود.
این معیار، توافق با قاعدهٔ تألیفیِ انتخاب اقدام است؛ سنجش احساس درونی یا ارزیابی
بالینی نیست. برای بخش ترس/خستگی، وضعیت بدن هم ساختگی است؛ این نشست حرکت
واقعی در موتور بدن اجرا نمی‌کند. متن، حافظه و سیاست این عامل بیرونی ثبت می‌شوند؛
وزن مدل پایه یا گفت‌وگوی ChatGPT تغییر نمی‌کند.

حداکثر هفت درخواست بدون تکرار خودکار ارسال می‌شود. هر درخواست پیش از ارسال
۴ سنت از بودجه رزرو می‌کند: مجموع رزرو حداکثر ۲۸ سنت، پایین‌تر از سقف یک دلار.
مصرف واقعیِ توکن و برآورد هزینه جداگانه ذخیره می‌شوند. مبلغ رزروشده صورتحساب نیست.
کلید GitHub فقط در سربرگ درخواست API استفاده می‌شود؛ ورودی‌ها هیچ اطلاعات
شخصی، بیمار یا کلید ندارند. همهٔ داده‌های آزمایش ساختگی و قابل انتشارند.

مدل `gpt-5.6-luna`، خروجی حداکثر ۶۰۰۰ توکن، ورودی حداکثر ۴۰۰۰۰ بایت و
سطح سرویس `default` است. قیمت رسمی بررسی‌شده در ۲۳ اکتبر ۲۰۲۶:
ورودی ۰٫۲۰ و خروجی ۱٫۲۰ دلار بر میلیون توکن. برای احتیاط، ورودی در برآورد
با نرخ نوشتن کش ۰٫۲۵ دلار محاسبه می‌شود. اجرای این مجوز پس از ۲۹ اکتبر متوقف است.

- https://developers.openai.com/api/docs/models/gpt-5.6-luna
- https://developers.openai.com/api/docs/guides/structured-outputs

دفتر `results/session.json` پیش از هر درخواست و پس از پاسخ با کنترل نسخهٔ GitHub
ذخیره می‌شود. اجرای مجدد پاسخ‌های تکمیل‌شده را مصرف می‌کند و درخواست نامعلوم
یا شکست‌خورده را دوباره ارسال نمی‌کند. نتیجهٔ سیاست روی دادهٔ جدید گزارش می‌شود؛
اگر امتیاز بهتر نشود، ادعای بهبود نمی‌کنیم. یک نمونه از هر حالت برای نتیجه‌گیری
آماری کافی نیست. سیاست پیشنهادی به‌طور خودکار در هستهٔ اصلی نصب نمی‌شود.

آزمون آفلاین:

```sh
python3 -m unittest experiments.affect_api_20261023.test_session -v
```

اجرای زنده فقط با commit فایل `authorization.json` روی شاخهٔ اختصاصی فعال می‌شود.
افزودن کد، بازکردن PR، ادغام در main و اجرای آزمون‌های معمول پولی نیستند.
