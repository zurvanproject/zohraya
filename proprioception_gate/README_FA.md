# ممیزی مستقل حس عمقی ناسورایا

این ابزار، ZIP دریافتی از Gemini را بدون استخراج یا اجرای کد داخل آن بررسی می‌کند.
آزمون‌های نرم‌افزاریِ این مخزن با Python استاندارد اجرا می‌شوند و نیازی به API یا
مدل زبان ندارند. نتیجهٔ **موفقیت حسابی** به معنی اثبات تعادل، صحت فیزیک،
ایمنی زیستی، کارکرد حسگر واقعی یا یادگیری مستقل نیست.

روش بازتولید از ریشهٔ مخزن:

```bash
python3 -m unittest discover -s proprioception_gate/tests -v
python3 -m proprioception_gate.audit /path/to/NASURAYA_PROPRIOCEPTION_V1.zip --report /tmp/proprioception-audit.json
```

در صورت خطا، فرمان با کد ۱ پایان می‌یابد. در حالت موفق تنها وضعیت
`ARITHMETICALLY_CONSISTENT_NOT_PHYSICALLY_VALIDATED` مجاز است.

آنچه بررسی می‌شود: نام و SHA256 تمام فایل‌ها، ساختار ده گزارش شبیه‌سازی،
درستی محاسبهٔ خطای پیش‌بینی COM و EUI، انطباق برچسب خطر، محدودیت زاویه و
گشتاور مفاصل شناخته‌شده و درصد کاهش RMSE در داده‌های تجمیعی Hold-out.
این کنترل‌ها جایگزین اجرای موتور روی یک شبیه‌ساز پویایی معتبر نیستند.

این ماژول عمداً با `runtimes/tadash_body` و PR #68 تعامل ندارد و هیچ وضعیت
پایداری را تغییر نمی‌دهد. جهت توسعهٔ کامل موتور، Issue #72 را ببینید.
