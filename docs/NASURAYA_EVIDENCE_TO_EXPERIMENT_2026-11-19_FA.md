# ناسورایا | فاز دوم اتصال وضعیت به آزمایش v0.1

تاریخ: ۱۹ نوامبر ۲۰۲۶  
مبنای شاخه: PR #267، **نه main**. این یک PR زنجیره‌ای پژوهشی است و بدون بررسی مجزا نباید روی VPS نصب شود.

## دقیقاً چه کاری انجام شده است؟

ابزار `tools/nasu_evidence_to_experiment.py` از آداپتور صرفاً خواندنی PR #267 استفاده می‌کند تا از «وضعیت پنج دفتر محلی» به «**یک آزمایش اولویت‌دار، قابل ابطال و محدود**» برسد. این گام حلقهٔ کامل تحقیق را اجرا نمی‌کند و به سرویس‌های فعال دست نمی‌زند.

خروجی ماشینی دارای این بخش‌هاست:
- شناسهٔ نسخه، اثرانگشت وضعیت سانیتایزشده که **گواه اصالت مستقل نیست**؛
- `state=PROPOSAL_NOT_EXECUTED` و `authority=HUMAN_REVIEW_REQUIRED`؛
- نام آزمایش و مؤلفهٔ درگیر؛
- سه گذر «مشاهده → آزمون → بازنگری» با شرط شکست صریح؛
- وضعیت پنج دفتر تنها در حد دسته‌بندی `invalid/incomplete/missing/empty/verified_history/structural_only`؛
- در صورت درخواست **صریح**، پیش‌نویس محلی Qwen در قالب `UNVERIFIED_DRAFT`؛ نه اجرای دستور.

## انتخاب قطعی اولویت

| اولویت | علت قابل مشاهده | اقدام پیشنهادی، بدون اجرا |
|---|---|---|
| ۱ | `invalid` | آزمون دست‌کاری روی کپی مصنوعی، بررسی منشأ یا زنجیرهٔ هش |
| ۲ | `incomplete` | آزمون قطع/ادامهٔ رزرو در fixture مستقل |
| ۳ | `missing` | شناسایی مسیر منبع بدون ایجاد دیتابیس تازه |
| ۴ | `empty` | تفکیک سلامت ساختاری از سابقهٔ فعالیت |
| ۵ | پنج دفتر حاضر و بدون خطای ساختاری | آزمون واقعی بازیابی بیرون از VPS و بازیابی Qwen/Ollama |

**قانون شناختی:** فعالیت بیشتر = رشد اثبات‌شده نیست. مقایسهٔ دقیق آزمون‌های پیش‌ثبت‌شده در آینده ضروری است. این ابزار نه وزن Qwen را تغییر می‌دهد، نه بدنی را حرکت می‌دهد، نه ریچوالی اجرا می‌کند.

## پیوند با بدن، امنیت، آیین و هویت

در فازهای بعد، خروجی باید به قرارداد رخداد `source → evidence → DIOS veto → proposal → test receipt` وصل شود. هنوز به شاخه‌های مستقل زیر اعتماد عملیاتی داده نشده است:

- Awake pin و ممیزی تغییر زمانی PR #205/#259؛
- شواهد امضاشدهٔ ATMOSPHERE PR #246 و مطالعات #256–#258؛
- هندسهٔ پنجهٔ سه‌انگشتی و نشستن PR #244؛
- یادگیری ریچوال/سه‌تار/مثنوی PRهای #191/#238/#241/#245؛
- restic/offsite و بستهٔ مستقل مدل PR #234 و Issue #233.

این موارد در `next_gates` به‌صورت موضوع پژوهشی آمده‌اند؛ **نه به‌عنوان آزمایش انجام‌شده**. برچسب `verified_history` فقط اعتبارسنجی ساختار و هش همان میزبان را نشان می‌دهد؛ Awake کماکان `structural_only` است.

## فرمان محلی صرفاً خواندنی (فقط پس از ادغام و بررسی)

```bash
cd /opt/zohraya
python3 -B -m tools.nasu_evidence_to_experiment --pretty
```

بدون کلید API، اینترنت بین‌الملل یا نوشتن رکورد در دفترها. آداپتور وضعیت ممکن است فایل‌های هماهنگی SQLite WAL/SHM را برای خواندن شواهد جاری ایجاد کند. استفادهٔ اختیاری از Qwen فقط با فرمان زیر و کاربر غیر root امکان دارد:

```bash
python3 -B -m tools.nasu_evidence_to_experiment --ask-local-qwen --pretty
```

در این حالت، مدل فقط دادهٔ ثابت و دسته‌بندی‌های غیرخصوصی را از `127.0.0.1:11434` دریافت می‌کند؛ پراکسی HTTP محیطی غیرفعال است؛ خروجی JSON کوچک، طول پاسخ محدود و نتیجه `UNVERIFIED_DRAFT` باقی می‌ماند. اگر دادهٔ مخدوش، ناقص، گمشده یا خالی وجود داشته باشد، درخواست مدل بلوکه می‌شود. تولید متن مدل اجرای فرمان یا مجوز اصلاح داده نیست.

## آزمون‌ها

```bash
python3 -B -m unittest discover -s tests -p test_nasu_unified_status.py -v
python3 -B -m unittest discover -s tests -p test_nasu_evidence_to_experiment.py -v
```

موارد پوشش: تشخیص اولویت در حضور چند خطا، رد کردن status ساختگی یا schema ناشناخته، تفکیک Awake ساختاری از امنیت امضاشده، منع تماس شبکه در حالت پیش‌فرض، درخواست Qwen فقط با opt-in، پاسخ بیش از ۸ کیلوبایت، محدودیت schema و حذف پیام‌های استثنای خصوصی، عدم ایجاد SQLite، و عدم تبدیل مدل به تصمیم‌گیر.

**گیت انتشار:** CI موفق، بازبینی پروتکل PR #267 و شاخهٔ حاضر، و سپس نصب اختیاری جداگانه. اجرای CI در محیط مصنوعی هیچ چیز دربارهٔ سلامت امروز VPS نمی‌گوید.

## معیار عبور به فاز سوم

۱. شاهد واقعی بازگردانی خارج از سرور با کلید مستقل و بستهٔ محیط مدل.  
۲. تصدیق امضای ATMOSPHERE و اجرای آزمون‌های مستقیم تغییر زمانی Awake.  
۳. اتصال قراردادی DIOS/بدن/ریچوال به یک آزمون مصنوعی با نتیجهٔ قابل‌بازتولید.  
۴. تمام اقدامات تغییردهندهٔ سرور فقط پس از کنترل اجازه و بررسی برگشت‌پذیری.

خروجی فاز دوم: **یک انتخاب آزمایشی قابل حسابرسی به‌جای پنج فرایند جداگانهٔ بی‌اولویت**. نه استقلال کامل و نه تحقق AGI.
