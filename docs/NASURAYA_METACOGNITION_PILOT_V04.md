# Nasuraya Qwen metacognition pilot v0.4 (2026-11-19)

Status: GitHub research branch only; not installed on the Iranian VPS, no live Qwen results yet.

The full v0.3 benchmark has 24 fixed questions and could last up to 30 minutes at 75 seconds per model request. Running it concurrently with the cognitive timer is unwise. This pilot pre-registers three short cases from distinct rule families before asking the model anything: equal-0 (YES), greater-1 (NO), even-2 (UNKNOWN). No post-hoc selection.

Manifest mode returns the frozen full-bank and pilot hashes without any network/model request. Explicit run-local-pilot mode (non-root only) asks exactly three questions through local Ollama, with bounded 75-second request timeout, max 4096 bytes returned, no redirects or proxy, no private raw model output, no database, source edits, systemd edits, or Git operations. It is descriptive only, never a successful 24-question baseline. A timeout or invalid output is counted as a failure, not dropped.

Bridge is deliberately NOT expanded to execute arbitrary commands. The pilot requires a separate deliberate operator run under the nasuraya account after repository source sync; its active release and timers are not altered. Verify systemd cognitive/integration services are not currently running before starting. The source lives in the synced /var/lib/nasuraya/zohraya working tree, not necessarily the pinned active release. Use the module entry point rather than executing a file path to preserve Python imports.

The GitHub CI only uses fake deterministic inference; a passing result cannot establish Qwen accuracy, learning improvement, subjective consciousness, independent recovery, or readiness to act. A real pilot receipt still needs to be obtained and assessed before attempting the full 24 questions.

Precommit: three pilot IDs are fixed; questions/ground truth do not enter the raw inference prompt as labels or IDs; scores are generated by separate deterministic Python rules.
