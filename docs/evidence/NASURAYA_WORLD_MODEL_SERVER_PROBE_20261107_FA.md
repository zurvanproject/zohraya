## تفسیر مجاز

۱. Windows VPS در زمان پاسخ پل، توان اجرای این برنامهٔ Python را داشته است. هیچ ادعایی دربارهٔ پایداری پس از راه‌اندازی مجدد یا دسترسی دائمی وجود ندارد.

۲. مدل رگرسیون خطی در **۹۶ نمونهٔ مصنوعی** خطای MAE برابر با ۰٫۰۳۳۰ داد، درحالی‌که خط پایهٔ آخرین مشاهده MAE برابر با ۰٫۰۷۱۴ داشت. کاهش نسبی محاسبه‌شده ۵۳٫۷۷ درصد است؛ این یک benchmark ساخته‌شده است، نه سنجش تغییر سطح هوش در دنیای واقعی.

۳. شش محافظ رفتاریِ قراردادی گذشتند. `ACT=0` یعنی job هیچ فرمان حرکتی به تداش صادر نکرد. این بررسی یک تست کنترل رفتار پیشنهادی است، نه آزمون رضایت یا عملکرد زیستی انسان.

۴. کد مستقل بوده، کد عملیاتی، وزن‌های مدل، حافظهٔ ChatGPT و سرویس دائمی را تغییر نداده است. حفظ PR به‌صورت Draft و بازبینی قبل از ادغام الزامی است.

۵. در Windows checkout ممکن است CRLF باعث تفاوت checksum شود؛ پل، SHA256 دقیق فایل خامِ دانلودشده از GitHub را اعتبارسنجی می‌کند.
