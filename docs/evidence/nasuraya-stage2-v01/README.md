Use standard gzip/JSON readers. No passwords, API keys or private credentials are
required. All truth is generated by the authored simulator. Timing is machine
dependent. State memory consistency is a property of the numeric stream, not of
the random or visible-label baselines. Novel/mixed type errors in the observer
are stricter than the eligible-only type classification denominator in report.json.

Negative results are intentional retained evidence: full detection accuracy did
not improve, intensity/type/location errors worsened, attention ablation did not
show a benefit, novelty recall was low, and noisy negative-window FPR was 96.28%.
Model parameters and frozen evaluator were not changed after reading these results.

See the Persian results report and `examples/nasuraya_runtime/STAGE2.md` for exact
commands, limitations, rollback and the next independent experiment.
