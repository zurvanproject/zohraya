# گفتگو، حافظه، پیش‌بینی و بدن در یک مسیر — ۲۶ اکتبر ۲۰۲۶

شاخهٔ یکپارچهٔ PR #67 اکنون main با شناسهٔ `4a2d687` و مسیریاب ممیزی‌شدهٔ PR #78 با شناسهٔ `da2b70d` را در تاریخچه دارد. پل گفتگوی موجود به حافظهٔ تجربهٔ ادغام‌شده در main متصل شده است. این تغییر یک مسیر اجرایی مشترک ایجاد می‌کند: پیام صریح → بازیابی دارای منشأ → تصمیم محدود → پیش‌بینی ثبت‌شده پیش از اجرا → یک رسید واقعی تداش → خطای پیش‌بینی و به‌روزرسانی حافظه.

## تغییر قابل مشاهده

در نشست تازه، پیام نخست با نبود تجربهٔ مرتبط از persistence استفاده می‌کند. پیام بعدی می‌تواند از `nearest_episode` روی نتایج قبلیِ همان وضعیت و ترجیح اقدام استفاده کند. متن گفتگو یا نتیجهٔ آینده وارد دادهٔ پیش‌بینی نمی‌شود. سابقهٔ محافظت بدن نیز پیش از انتخاب اقدام بازیابی می‌شود و می‌تواند گزینهٔ راه‌رفتن را محدود کند؛ حق رد مستقل بدن همچنان نهایی است.

هر پیام یک شناسهٔ پایدار دارد. گفتگو و تجربه از همان شناسهٔ رسید بومی استفاده می‌کنند و دو بار بدن را اجرا نمی‌کنند. تکرار پیام، بازخوانی trace، بازیابی و تثبیت حافظه چرخهٔ جدید بدن نمی‌سازند. بازیابی پس از ثبت نتیجهٔ بدن یا حتی ثبت یادگیری و پیش از ذخیرهٔ پاسخ گفتگو، نتیجه را بدون اجرای مجدد آشتی می‌دهد. نتیجهٔ نامعلوم اجازهٔ اجرای خودکار دوباره ندارد.

منشأها جدا ثبت می‌شوند: متن با `conversation://`، ارزیابی عاطفی به‌عنوان تفسیر تألیفیِ فراخواننده، و نتیجهٔ مشاهده‌شده با `native-decision://` و چکیدهٔ رسید. ذخیرهٔ یک گفته به معنای اثبات صحت محتوای آن نیست. فرضیه‌های تثبیت حافظه همچنان تألیفی و تأییدنشده‌اند.

## پیش‌بینی، دقت اقدام و هزینه

پیش‌فرض مسیر مشترک هیچ API فراخوانی نمی‌کند. پیش‌بینی اقدام و خطای چهار شاخص عددی جدا ثبت می‌شوند. مسیریاب PR #78 بدون تغییر حفظ شده است: برای امتیازدهی عددی API، دو دستهٔ مستقل با حداقل ۲۰ گروه منشأ در هر دسته، بهبود حداقل ۱۰٪ و ۰٫۰۰۰۱ در MAE نسبت به هر دو خط مبنا، نبود پسرفت هر شاخص و آزمون علامت گروهی با آستانهٔ ۰٫۰۱۲۵ لازم است. استقلال واقعی منشأ باید جداگانه ممیزی شود؛ چکیدهٔ فایل آن را ثابت نمی‌کند.

این پل هیچ مدرک تازه‌ای برای بازکردن دروازه ندارد و API زنده یا ورودیِ ارتقای خودکار ارائه نمی‌کند. قرارداد مقایسهٔ پولی فقط پیشنهاد walk را پوشش می‌دهد؛ پیش‌بینی observe صرفاً محلی است. حافظه اجازهٔ هزینه یا حرکت تازه ایجاد نمی‌کند. ۳۸ فایل آزمایش، مجوز، نتیجه و مسیریاب PR #78 بدون تغییر نگه داشته و با `nasuraya.verify_sources` کنترل می‌شوند. پایان بازهٔ مجوز نیز آزمایش دو‌درخواستیِ تکمیل‌شده را دوباره مجاز نمی‌کند.

نمایش تازه دو گذار متوالی مصنوعی دارد: هر دو اقدام walk درست پیش‌بینی شد؛ روش‌ها به‌ترتیب persistence و nearest_episode بودند؛ MAE برابر ۰٫۰۰۰۱۴۹۵۷۲۰۴۴۰۱۴۳۶۰۲۴، هزینهٔ افزودهٔ API صفر، و تکرار در پردازش تازه صفر چرخه بود. **این دو گذار دادهٔ مستقل یا قابل‌مقایسه با آزمایش ۱۲‌گذاری قبلی نیستند** و نشانهٔ برتری عددی تازه بر API محسوب نمی‌شوند. تصمیم اجرایی همچنان تقویت و ارزیابی حافظه پیش از آزمایش پولی بیشتر است.

## اجرای قابل بازتولید

```bash
python -m nasuraya.verify_sources
python -m nasuraya dialogue test
python -m nasuraya body experience-test
python -m unittest experiments.affect_api_20261023.test_prediction_router -v
python -m nasuraya continuity-demo --output /tmp/nasuraya-continuity-demo
python -m nasuraya dialogue trace --session-dir /tmp/nasuraya-continuity-demo/session --message-id second
python -m nasuraya dialogue recall --session-dir /tmp/nasuraya-continuity-demo/session --cue body
python -m nasuraya dialogue consolidate --session-dir /tmp/nasuraya-continuity-demo/session
```

خلاصهٔ اجرای واقعیِ مصنوعی و خروجی آزمون‌ها در [پوشهٔ شواهد](../integration/refresh-v03/) ثبت می‌شود. آزمون‌ها قطع اجرا، تکرار، جدایی منشأ، ترتیب پیش‌بینی/مشاهده، محفوظ‌ماندن بودجه، انتخاب محتاطانه پس از محافظت و ادامه در پردازش تازه را بررسی می‌کنند.

در این بازبینی **۲۸۹ آزمون در هفت مجموعه گذشت؛ صفر شکست و صفر آزمون صرف‌نظرشده**: گفتگو ۱۹، تجربه و سازگاری API ۲۵، رابط و مشاهدهٔ خود ۱۵، مسیریاب ۱۹، میزبان ۱۱۰، ژنوم ۹۸ و ترکیب قابلیت‌های بدن ۳. این شمارش مجموعهٔ تاریخی ۱۰۲۵‌آزمونی را تکرارشده فرض نمی‌کند.

## سازگاری و حدود اجرا

دو فایل هم‌نام experience هنگام ادغام معنای متفاوت داشتند. سازندهٔ بستهٔ کم‌حجم API به `api_experience.py` منتقل شده و دو ورودی قبلی آن به‌صورت lazy سازگار مانده‌اند؛ کنترل‌گر تجربهٔ main نیز حفظ شده است. فرمان‌های مستقل هر دو مسیر و آزمون‌هایشان برقرارند. قرارداد سخت‌گیرانهٔ JSON و مرجع قابل‌اعتماد ژنوم از main حفظ شده است.

این نسخه در شاخهٔ آزمایشی یکپارچه است؛ main و شاخهٔ وضعیت زنده تغییر نمی‌کنند. پنج فایل اصلی میزبان پژوهشی دقیقاً محفوظ‌اند. زمان‌بندی فعال نشده و فراخوانی پولی انجام نشده است. برای این نسخه باید نشست تازهٔ صریح با سقف ۱ تا ۳ اقدام ساخت؛ دفترهای قدیمیِ وابسته به چکیدهٔ کد خودکار مهاجرت نمی‌کنند. اتصال گفتگو همچنان با فراخوانندهٔ صریح است؛ شنوندهٔ خودکار ChatGPT وجود ندارد. این نمایش از بدن تجمیعی نرم‌افزاری تداش استفاده می‌کند و ارزیابی تازه‌ای از بدن مفصل‌دار یا سخت‌افزار نیست.

درس عملی مقایسهٔ پروژه‌ها به زنجیرهٔ قابل آزمونِ منشأ، تصمیم، نتیجه و اصلاح تبدیل شد. سنجش هم‌سطح با پروژه‌های دیگر، حل عمومی تعارض همهٔ ۷۷ حکمت یا ارزیابی تجربهٔ ذهنی ادعا نمی‌شود.
