# تطبیق ایجاد نشست و تکمیل هدف زنده

پایه: PR #13، commit `b9830fc`. شاخهٔ مستقل:
`nasuraya/creation-reconciliation-v01`. CI پایه موفق است.
پس از تأیید صریح کاربر برای انتقال داده‌های مصنوعی به `api.openai.com`،
همان کلید و همان هدف `growth-live-20261014` ادامه یافت. کلید یا grant تازه
ساخته نشد. مجوز قبلی یک کنش و شش فراخوانی ابزار مدل بود.

## تطبیق مخصوص میزبان

رزرو creating بدون شناسه همچنان در runner و زمان‌بند توقف ایجاد می‌کند.
خطای اتصال به معنی نبودِ نشست یا موفقیت مأموریت نیست. ابتدا یک GET فقط‌خواندنی
فهرست کاملِ خالی نشست‌های پروژه را برگرداند. تابع جدید میزبان دو خواندن دیگر،
بدون فیلتر agent یا cursor، انجام داد؛ هر دو `data=[]` و `has_more=false` داشتند.

این مسیر به دو تصدیق صریح میزبان نیاز دارد: درخواست قبلی پایان یافته است و
نویسندهٔ دیگری در حال ایجاد نشست در همان پروژه نیست. فهرست خالی، شواهد وضعیت
فعلی API است؛ تاریخچهٔ نامعلوم درخواست قبلی را اثبات یا موفق معرفی نمی‌کند.
اگر این فرض‌های میزبان قابل احراز نباشند، این فرمان نباید اجرا شود. پاسخ
غیرخالی، ناقص، بدشکل یا خطای خواندن، رزرو را حفظ می‌کند. وجود هر فراخوانی
محلی یا پیامد نامعلوم نیز مانع است.

ثبت رسید بررسی و حذف فقط رزرو بی‌شناسه، در یک تراکنش انجام می‌شود؛ توقف
یا خطای ذخیره نمی‌تواند فقط یکی را ثبت کند. تکرار بررسی همان رسید را می‌خواند
و رزرو تلاش بعدی را حذف نمی‌کند. این تابع ابزار مدل نیست، از runner فراخوانی
نمی‌شود و هیچ grant، بودجه یا قرارداد wake را تغییر نمی‌دهد.

```sh
python -m examples.nasuraya_body_loop reconcile-api-creation \
  --session /private/session.sqlite --run-id saved-goal \
  --confirm-finished-create --confirm-exclusive-project-writer
python -m examples.nasuraya_body_loop creation-test
```

## نتیجهٔ واقعاً اجراشده

اجرای جدید با فرمان صریح میزبان انجام شد. پنجرهٔ wake قبلی منقضی مانده است؛
این نتیجه را اجرای زمان‌بندی‌شده گزارش نمی‌کنیم. آزمون زمان‌بندی‌شدهٔ زندهٔ
قبلی در PR #12 و شواهد آن جدا باقی است. میزبان دائمی همچنان فراهم نیست.

| سنجه | نتیجهٔ جدید |
|---|---|
| مدل زنده | `gpt-6-astra` |
| نسخهٔ بدن | ۴ → ۵ |
| کنش واقعی نرم‌افزاری | یک `observe` |
| ابزار مدل | ۵ از سقف ۶؛ یک ابزار باقی، صفر کنش باقی |
| هدف | تکمیل‌شده، بدون پیامد نامعلوم یا شکست |
| خاطرهٔ ورودی | سه تجربهٔ تأییدشده |
| پیوند intent به نتیجه | پیشنهاد مدل و انتخاب هسته و پیامد بدن: `observe` |
| علت ذخیره‌شده | فشار خواب بالا؛ قاعدهٔ میزبان، نه استدلال پنهان مدل |
| بازخوردهای بازیابی‌شده | دو رکورد |
| تاریخچه | چهار تصمیم و دو خاطرهٔ care پیشین بدون تغییر |
| نشست remote | تکمیل‌شده و حذف‌شده |

اثر علّی حافظه بر GPT از این یک اجرا سنجیده نمی‌شود؛ همان مقایسهٔ ۳۲ وضعیت
مصنوعی PR #13 معتبر باقی است و مقایسهٔ چندبارهٔ مدل واقعی هنوز انجام نشده است.

## بازخوانی سرد

فرمان زیر در فرایندی تازه اجرا شد. SDK و کلید بارگذاری نمی‌شوند؛ تمام متدهای
API، ساخت دوبارهٔ ورودی و اجرای چرخهٔ بدن با guard ممنوع شده‌اند. خروجی
`completed/saved_terminal` با **صفر شبکه، صفر ابزار تازه، صفر کنش تازه** بود؛
حالت، بودجه و تاریخچه برابر ماندند. این بازخوانی اجرای زندهٔ تازه نیست.

```sh
python -m examples.nasuraya_body_loop terminal-replay-check \
  --session /private/session.sqlite --run-id completed-goal \
  --output-dir /private/new-replay-proof
```

شاهد عمومی کاهش‌یافته در `evidence/creation-reconciled-live.json` است؛ کلید،
شناسه‌های remote و متن reasoning در آن نیستند. checkpoint خصوصی نسخهٔ ۵
برای ادامه نگه‌داری می‌شود. ادامهٔ یک هدف تازه نیازمند مجوز محدود میزبان است؛
تکمیل این هدف مجوز صدور خودکار هدف یا بودجهٔ بعدی نیست.
