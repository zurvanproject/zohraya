# پایش محدود عصر ناسورایا — ۷ نوامبر ۲۰۲۶

هدف مجاز: از زمان نصب تا ساعت ۲۲ به وقت تهران، هر ده دقیقه یک نمونه از وضعیت خدمت و دفترهای حافظه ثبت شود و در پایان گزارش آماده شود. مهلت ثابت UTC: `2026-11-07T18:30:00Z`؛ منطقهٔ نمایش `Asia/Tehran`.

این برنامهٔ استاندارد Python هیچ اتصال شبکه، فراخوانی مدل یا دسترسی به کلید API ندارد. دفتر بومی و دفتر مدل با SQLite فقط‌خواندنی و query_only باز می‌شوند. نویسنده فقط SQLite و گزارش پوشهٔ اختصاصی پایش است.

در هر نمونه: quick_check هر دو دفتر، checksum ذخیرهٔ بدن، revision و شمار عمل‌های بومی، hash رکوردهای تصمیم و اهداف پیشین، تعداد درخواست‌های مدل، تازگی ضربان، شناسهٔ راه‌اندازی خدمت و وضعیت وظیفهٔ SYSTEM بررسی می‌شوند. وضعیت مورد انتظار آغاز پایش، revision=9 و prefix `36ef52e76264c1bb` است. هر تغییر ثبت می‌شود؛ این برنامه تعمیر خودکار، بازنشانی یا هدف تازه‌ای انجام نمی‌دهد.

نصب‌کننده، منبع sampler و خدمت موجود را با SHA-256 ثابت تأیید می‌کند و دو وظیفهٔ محدود می‌سازد: یک sampler با فاصلهٔ ده دقیقه و یک finalizer در مهلت ثابت. هر دو SYSTEM هستند و خط فرمان `-I -X utf8` دارند. در صورت شکست شروع، فقط وظایف همین نصب حذف می‌شوند. خدمت اصلی و پل فعلی تغییر نمی‌کنند. نصب دوبارهٔ همان برنامه نباید نقطهٔ شروع، مهلت یا گزارش را بازنشانی کند.

محل خصوصی: `%PROGRAMDATA%/NasurayaModelWorker/monitoring/evening-20261107`. فایل‌های مهم: `config.json`، `watch.sqlite`، `final-report.json` و `final-report.txt`. مجوزهای محدود والد به SYSTEM و Administrators به ارث می‌رسند. متن گفتگو و کلید در نمونه‌ها کپی نمی‌شوند؛ hash رکوردها نگهداری می‌شود.

گزارش شامل شمار نمونه‌های سالم/ناموفق، نمونه‌های جاافتاده، بزرگ‌ترین فاصلهٔ مشاهده، تعداد boot-idهای دیده‌شده، آخرین revision و وجود نمونهٔ نهایی است. این پایش نمونه‌ای است: توقفی کوتاه بین دو نمونه ممکن است دیده نشود. `coverage_ok` فقط پوشش زمانی را توصیف می‌کند؛ `bad_samples` جداگانه سلامت را مشخص می‌کند. نبود نمونهٔ نهایی با گزارش ناقص معرفی می‌شود.

چهار آزمون بدون شبکه، fixture اصلی بومی را استفاده می‌کنند: فقط‌خواندنی‌بودن و تشخیص checksum نامعتبر، جلوگیری از ثبت دوبارهٔ یک بازه و کشف تغییر شمار API، و گزارش صادقانهٔ بازه‌های جاافتاده و پایان دیرهنگام؛ همچنین تطبیق مهلت مرجع با ساعت داخلی سرور. آزمون‌های CI روی Windows و Linux اجرا می‌شوند؛ ثبت و نخستین نمونهٔ SYSTEM روی VPS واقعی بررسی خواهد شد.

برای توقف فقط این پایش، مدیر سرور دو وظیفهٔ `NasurayaEveningWatch20261107Sample` و `NasurayaEveningWatch20261107Final` را غیرفعال می‌کند. این کار خدمت مدل را متوقف نمی‌کند.
