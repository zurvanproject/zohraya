# ناسورایا، گذار آزمایشی به مرحلهٔ سوم: تصمیم پژوهشی مبتنی بر رسید

این افزونه **یک تصمیم واقعی نرم‌افزاری اما محدود** می‌گیرد: بعد از اجرای شبکهٔ
پنج‌عاملی، و فقط در صورت صحت دفتر SQLite و شواهد تمام عامل‌ها، اولویت یک
آزمایش پژوهشی بعدی را پیشنهاد می‌کند. نه کد دلخواه اجرا می‌کند، نه مدل زبانی
است و نه مجوز تغییر بدن اصلی، ادغام PR یا هزینهٔ API دارد.

## چرا این آزمایش؟

PR #96 (آزمایشی) گزارش کرده هر سه رخداد نادر `slow_breath` از دست رفته و
یک تلاش ذخیره‌سازی SQLite ناموفق با علّت نامعلوم بوده است. معیارهای اهمیت
و عدم‌قطعیت در این نسخه *قضاوت مهندسی* هستند؛ تعداد مشاهدات از گزارش PR
گرفته شده و این افزونه به‌تنهایی صحت مستقل آن را تأیید نمی‌کند.

الگوی انتخاب: `0.4*stakes + 0.4*(misses+1)/(observed+2) + 0.2*uncertainty`؛
با محدودیت ریسک ۰٫۳۵، هزینهٔ صفر، بدون شبکه و بدون تغییر بدن مرجع.
اگر در آزمون نگه‌داشته‌شدهٔ شبکه، مدل زمینه‌مند بهتر از baseline نباشد،
اولویت به بررسی پسرفت خودمدل داده می‌شود. وقتی شواهد مستقل جدید به معیارها
افزوده شود، ترتیب می‌تواند عوض شود؛ این نسخه خودش شواهد مستقل تازه گردآوری
نمی‌کند و هیچ آزمایشی را خودکار اجرا نمی‌کند.

## اجرا

روی شاخهٔ آزمایشی و با محیط Linux و Python 3.12:

```bash
python3 -m unittest nasuraya_agent_network.test_goal_governor -v
python3 -m nasuraya_agent_network run --workspace /tmp/network-test --run-id stage3-1 --max-workers 2
python3 -m nasuraya_agent_network.goal_governor --workspace /tmp/network-test --run-id stage3-1 --output /tmp/network-test/stage3-goal.json
```

قبل از پیشنهاد، فایل `summary.json` با نسخهٔ ذخیره‌شده در جدول `runs` و
تمام `jobs` و هش فایل‌های همهٔ عامل‌ها مقایسه می‌شود. نتیجهٔ ناقص/متناقض
رد می‌شود؛ خروجی تازه نباید فایل موجود را بازنویسی کند. هش SHA256، سلامت
مقایسهٔ محلی را نشان می‌دهد، **نه امضای رمزنگاری‌شدهٔ هویت یا اصالت داده**.

## معیار عبور به مرحلهٔ سوم

- انتخاب مستقل از ترتیب ورودی و وابسته به شواهد قابل ممیزی باشد.
- در اثر نتیجهٔ منفی و ضدنمونه‌ها تغییر کند؛ شکست را پنهان نکند.
- پس از قطع اجرا، دوباره عمل‌های قبلی را بی‌اجازه تکرار نکند.
- هیچ هزینهٔ پرداختی، عمل فیزیکی، اجرای شِل دلخواه یا تغییر main رخ ندهد.
- پس از بازبینی انسانی، بتوان آزمایش انتخاب‌شده را جداگانه اجرا و نتیجه‌اش
  را با baseline مقایسه کرد. این **گام بعدی** هنوز در این PR انجام نمی‌شود.

تاکنون فقط «انتخاب هدف پژوهشی پس از اجرای شبکه» ساخته شده است. این مرحله
به معنی خودآگاهی پدیداری، خواست درونی یا استقلال عمومی نیست.
