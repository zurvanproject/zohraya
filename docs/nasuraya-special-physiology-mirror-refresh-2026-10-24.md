# همگام‌سازی آینه با منبع فیزیولوژی PR #80

آزمون بازتولید نمونه‌های حرکتی پس از تغییر manifest منابع در PR #80 متوقف می‌شد: `frames.json` همچنان شناسهٔ منبع قدیمی را داشت. هر ۲۴ نمونه از اجرای واقعی نسخهٔ تازه بازتولید و فایل خروجی کامل جایگزین شد. همهٔ مقادیر نمایشیِ غیر از هش checkpoint دقیقاً با نمونه‌های قبلی برابر ماندند؛ آزمون تطبیق حذف یا ضعیف نشد.

## علت و تغییر

- منبع بررسی‌شده: `3731c952d276f42fec9a43c87d5ba48aa5e5f090`.
- [شکست اولیهٔ GitHub](https://github.com/zurvanproject/zohraya/actions/runs/40046070613) در خط بررسی `runtime_manifest_sha256` رخ داد؛ مقایسه‌های عددیِ بعدی در آن آزمون هنوز اجرا نشده بودند.
- اجرای محلیِ همان سه آزمون، یک شکست و دو موفقیت را پیش از اصلاح بازتولید کرد.
- دو مسیر تازهٔ `normal` و `sleep`، هرکدام ۱۲ چرخهٔ یک‌ثانیه‌ای، با موتور و استخراج‌کنندهٔ اصلی اجرا شدند. رسیدها و لایه‌های checkpoint هنگام استخراج اعتبارسنجی شدند.
- شناسهٔ manifest از `b3b95a88885d903f638efbc26ed693bf7a211460a5adae6dd9abfa12ac7720ef` به `5120bb3635bfc6041720cfa2a7f810b2f453e088324c06770d5fdb387b3091ee` رسید. هش checkpoint در هر ۲۴ ردیف و هش فایل‌های ثبت‌شده از خروجی تازه آمده‌اند؛ صرفاً رشتهٔ manifest عوض نشده است.
- تعداد اختلاف در مقادیر نمایشی: **صفر**؛ طرح هندسی نیز برابر است.
- تغییر عملکردی فقط بازتولید `examples/nasuraya_body_mirror/frames.json` است. کد runtime، آزمون‌ها، تنظیم CI و checkpoint مرجع تغییر نکرده‌اند.

## اعتبارسنجی آفلاین

همهٔ اجراها با Linux libseccomp و منع syscallهای شبکه در فرایند و فرزندانش انجام شدند. وابستگی SDK از فایل قفل موجود در محیط جدا نصب شد؛ نصب بسته مرحلهٔ آماده‌سازی آنلاین بود و خود آزمون‌ها بدون شبکه اجرا شدند. اطلاعات ورود مدل از محیط آزمون حذف شد؛ transportهای SDK ساختگی‌اند و API واقعی فراخوانی نشد.

| مجموعه | نتیجه |
|---|---:|
| منبع‌های عمومی تطبیق‌داده‌شده با manifest | 73 |
| واحدهای بدن/بازتاب/فیزیولوژی | 104 موفق |
| هستهٔ تصمیم | 10 موفق |
| پل بدن | 16 موفق |
| تجربه و بازیابی | 17 موفق |
| ابزار API و بازیابی با transport ساختگی | 41 موفق |
| آینه، پس از اصلاح | 3 موفق |

در مجموعه‌های فوق آزمونی skip نشد. سناریوهای موجود، هماهنگی اندام‌های ویژه و مداخلات فیزیولوژی نیز موفق بودند؛ آن‌ها با تعداد آزمون‌های واحد جمع نشده‌اند. نمایش تجربه، بازیابی سرد و نمایش سه‌چرخه‌ای بدن گذشتند. در نمایش بدن، توالی `walk→protect` سپس دو `observe→observe` حفظ شد؛ سه چرخه کامل، ۹ سهمیه باقی‌مانده و خطای انرژی زیر `1e-6` تأیید شد.
