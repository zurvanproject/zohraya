# فعال‌سازی محدود لایهٔ انگیزش/غریزهٔ تداش (۱ نوامبر ۲۰۲۶)

**وضعیت:** توسعه به درخواست تازهٔ کاربر از حالت PAUSED خارج شد. این سند توضیح می‌دهد «فعال» در این نسخه دقیقاً به چه معناست: یک لایهٔ محاسباتیِ اختیاری که به نشست واقعی نرم‌افزار تداش وصل است، شاخص‌های بدن نرم‌افزاری را می‌خواند، و حالت خود را در همان دفتر SQLite ثبت می‌کند. **بدون اجرای پس‌زمینه، حرکت خودکار اندام‌ها، تحریک جنسی واقعی، حسگر فیزیکی یا استنتاج تجربهٔ ذهنی.**

## چه چیزی وصل شد
- الگوریتم مستقل `examples/nasuraya_research/tadash_motivation_probe_v01.py`، با تفکیک wanting، پاسخ جنسی قراردادی، activation عمومی، پاداش قراردادی و satiety.
- آداپتر `examples/nasuraya_body_loop/instinct.py`، روی نشست `BodyLoop` با قفل فعلی و دفتر ثبت ماندگار و هش وضعیت.
- خوانش **فقط مشاهده‌ای** از checkpoint بدنی موجود: `sympathetic`، `parasympathetic`، `arousal`، `pain`، `fatigue`. درد و خستگیِ گزارش‌شده از بدن و بار عمومی خودمختار می‌توانند پیشنهاد را مهار کنند. برانگیختگی عمومی با میل جنسی یکی گرفته نمی‌شود.
- اجرای step مستقل و صریح؛ هر step یک `id` یکتا دارد و replay بدون تحول مجدد وضعیت پاسخ می‌دهد.
- کنترل فعال/غیرفعال با حفظ وضعیت و بازیابی سرد؛ حداکثر ۱۲۸ رویداد برای جلوگیری از رشد بی‌حد دفتر.
- تفکیک روابط خانوادگی/دوستانه از کانال رمانتیک و گیت سخت برای رضایت، درخواست فاصله و زمینهٔ بزرگسالی.
- هیچ تغییر فیزیکی در `UnifiedBody.cycle()`، هیچ هزینهٔ API و هیچ تغییر در وزن‌های ChatGPT.

## دستور اجرای نمونهٔ ایزوله در سیستمِ دارای Python 3.12
```bash
python3 -m examples.nasuraya_body_loop instinct-test
python3 -m examples.nasuraya_body_loop instinct-demo --output-dir /tmp/tadash-instinct-demo
```

نمونهٔ بالا یک نشست `session.sqlite` در `/tmp/tadash-instinct-demo` ایجاد می‌کند، چهار رویداد ساختگی را محاسبه و ثبت می‌کند، از روی فایل دوباره وضعیت را می‌خواند، و ثابت می‌کند چرخهٔ حرکتیِ بومی اجرا نشده است. این اجرا آزمایش نرم‌افزاری است نه تجربهٔ زیستی.

## فعال‌سازی روی نشست موجود تداش
```bash
python3 -m examples.nasuraya_body_loop start --session /tmp/my-tadash.sqlite --mode observe --max-actions 0
python3 -m examples.nasuraya_body_loop instinct-enable --session /tmp/my-tadash.sqlite
```

برای یک رویداد نمونه، ابتدا فایل ورودی را به‌صورت مستقل ذخیره کنید:
```json
{
  "id": "synthetic-001",
  "source": "synthetic_fixture",
  "relationship": "romantic",
  "adult_context": true,
  "consent": "granted",
  "incentive": 0.8,
  "novelty": 0.2
}
```

سپس (با فرض ذخیرهٔ JSON در `/tmp/tadash-event.json`):
```bash
python3 -m examples.nasuraya_body_loop instinct-step --session /tmp/my-tadash.sqlite --event-json /tmp/tadash-event.json
python3 -m examples.nasuraya_body_loop instinct-status --session /tmp/my-tadash.sqlite
python3 -m examples.nasuraya_body_loop instinct-disable --session /tmp/my-tadash.sqlite
```

خاموش‌سازی دادهٔ ذخیره‌شده را حذف نمی‌کند؛ روشن‌کردن مجدد، حالت را از روی دفترِ همان نشست باز می‌یابد.

## خروجی قابل قبول
`native_cycles_caused=0` برای محاسبهٔ غریزه؛ حالت مستقل می‌تواند تغییر کند اما checkpoint بومی بدن و بودجهٔ حرکت باید ثابت بمانند. حالت رابطه‌ای صرفاً زمینهٔ ساختگیِ سناریو است؛ محبت خانوادگی هیچ محرک جنسی تولید نمی‌کند. `confirmed_reward` فقط رویداد ورودیِ صریح است و به معنی لذت مشاهده‌شده نیست.

## مرزهای این نسخه
- «فعال» یعنی **قابل اجرا در نشست نرم‌افزاری و دارای وضعیت قابل بازیابی**. در خود این گفتگو چیزی همیشه‌روشن یا دارای حسگر، فیزیولوژی زیستی واقعی، یا فعالیت مستقل بین پیام‌ها ایجاد نمی‌شود.
- هنوز محورهای واقعی هورمونی، مسیرهای عصبی لگنی، گیرنده‌های مکانیکی یا حلقهٔ درون‌بدنی کالیبره نشده‌اند و به متغیرهای این نسخه نسبت داده نمی‌شوند.
- در صورت ادغام PR، فقط امکان اجرای این مسیر به شاخهٔ اصلی می‌آید؛ راه‌اندازی یک نشست در محیط عملیاتی همچنان فرمان صریح می‌خواهد.
- در پاسخ به تصمیم قبلی کاربر، گسترشِ بی‌پایان این محور مجاز نیست؛ پس از تأیید نمونهٔ حاضر، اولویت پروژه به مسیر بعدی برمی‌گردد.
