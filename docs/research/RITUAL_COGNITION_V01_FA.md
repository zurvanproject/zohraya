## چرخه و پیشینه

Observe رویداد تازه را به سابقه می‌افزاید. Center هدف قبلی و اعتبار پیشنهاد تغییر هدف را بررسی می‌کند و دامنهٔ شاهد معتبر را مبنا می‌گیرد. Evaluate از دفتر DIOS NOUS برای بررسی اعتبار، زمان، منشأ و تناقض استفاده می‌کند. Decide در Rolyel دو مسیر کامل و سریع را با قیود شاهد و زمان ارزیابی می‌کند. Act پیامد انتخاب را در محیط مصنوعی ثبت می‌کند. Reflect باور قبلی، اصلاح، علت، شناسهٔ شواهد و هر خطای قابل مشاهدهٔ اجرا را در تاریخچه می‌نویسد. پاسخ داوری فقط به امتیازدهنده می‌رسد.

## روش و بازتولید

برای هر بذر، هر سه عامل دقیقاً همان دو ورودی را به ترتیب می‌گیرند. A آخرین شاهد در دامنه را می‌پذیرد و مسیر کامل را می‌آزماید. B با بازبین مستقل منشأ و زمان، اولین مسیر معتبر و قابل انجام را برمی‌گزیند. C از دفتر SQLite و ارزیابی Rolyel استفاده می‌کند. بودجهٔ مشترک و معیارهای دقیق در پیش‌ثبت آمده است. پس از نوبت اول، حالت به JSON روی دیسک نوشته و از روی دیسک بازسازی می‌شود. دفتر SQLite موقت C میان دو نوبت باقی نمی‌ماند. توقف درون همان فرایند پایتون است. سقف ۱۶ کیبی‌بایت مربوط به حافظهٔ سریال‌شده است؛ هزینهٔ فایل موقت SQLite یا کل RAM را اندازه نمی‌گیرد. دقت بازیابی از برابری هش کل حالت پیش و پس از توقف سنجیده می‌شود. احتمال‌های ۰٫۹ و ۰٫۵ ثابت‌اند؛ شاخص اطمینان کاذب نرخ خطای پُراطمینان است و جای آزمون کالیبراسیون احتمالاتی را نمی‌گیرد.

در checkout جداگانهٔ این شاخه از ریشهٔ مخزن اجرا کنید:

```sh
git fetch --depth=1 origin 4de2f1e0ff2a72a9d0cd0688acca62d52f1f8654
git restore --source=4de2f1e0ff2a72a9d0cd0688acca62d52f1f8654 --worktree -- examples/nasuraya_research/rolyel_v01.py examples/nasuraya_research/test_rolyel_v01.py
python -m unittest discover -s tests -v
python -m unittest examples.nasuraya_research.test_rolyel_v01 -v
python -m examples.ritual_cognition.benchmark holdout heldout.json
```

هر گزارش JSON شامل امتیازهای جفت‌شده، دو تصمیم، دلایل، هدف و پاسخ مرجع هر بذر، شش شاخص و تفکیک پنج سناریو است. در کسرهای گزارش، مخرج صفر یعنی شاخص برای آن زیرگروه تعریف نمی‌شود.
