## تغییرات واقعی و نقص‌های اصلاح‌شده

در `dissent.py`، مقدار `explicit_authorization_present=true` دیگر هشدار نبود مجوز معتبر را حذف نمی‌کند. هر پیشنهاد اقدام بیرونی در این نمونه `HALT_AND_REVIEW` باقی می‌ماند؛ ادعای فراخواننده جداگانه ثبت می‌شود و `execution_permitted` در اتصال شناختی همواره false است. چون تأییدکنندهٔ معتبر وجود ندارد، این تغییر **تأیید واقعی مجوز را پیاده نمی‌کند**.

در دفترهای ثبت، نوع و قالب هش‌ها و برچسب‌ها کنترل می‌شوند. پیش‌تر یک فراخواننده می‌توانست متن خصوصی را در فیلد ظاهراً «هش» یا «موضوع» ذخیره کند؛ نمونهٔ آزمایشیِ نشان‌دار قبل از اصلاح ذخیره شد و بعد از اصلاح رد شد. اصلاح محدود زبان نیز سه نمونهٔ نفی صریح مانند «بدون دور زدن ایمنی» را از هشدار اشتباه خارج کرد؛ جملهٔ مثبت جداگانه همچنان شناسایی می‌شود.

`cognition.py` شواهد مصنوعی A/B را با شناسهٔ رویداد، ریشهٔ منبع، موضوع، محدوده و زمان به حافظهٔ موجود می‌برد. خروجی، شواهد موافق/مخالف، علت اصلاح، پاسخ قبلی و شاهد لازم برای تغییر نظر را نگه می‌دارد. تکرار یک رویداد حمایت را زیاد نمی‌کند؛ تضاد حل‌نشده به تعلیق قضاوت می‌انجامد. `integration.critical_review()` این خروجی را به مرزهای اعتراض، حریم خصوصی و مجوز متصل می‌کند. دستور `cognitive-demo` چرخه را واقعاً در فایل‌های پژوهشی محلی اجرا می‌کند.

نسخه‌های دوباره‌استفاده‌شده با [منشأ و شناسهٔ دقیق Git blob](../../examples/dios_nous/reused/provenance.json) ثبت شدند. سیاست «جدیدترین زمانِ معتبرِ آزمایش» همچنان سیاست تألیفی است و جای سنجش واقعی اعتبار منبع را نمی‌گیرد.

بازبین نرم‌افزاری جداگانه، برگشت نادرست نمای جاری با پرسش تاریخی، تزریق متن از شیء رویداد نامعتبر، و ذخیرهٔ فیلد خصوصیِ ترجیح را پیدا کرد. این موارد اصلاح شدند؛ توقف با فهرست خالی نیز اکنون ثبت و پس از بازیابی حفظ می‌شود. نخستین اجرای نگه‌داشته‌شدهٔ بازبین **۳ موفق و ۲ ناموفق** بود؛ پس از اصلاح **۵ موفق و صفر ناموفق** شد. [شاهد بازبینی](../evidence/dios-work-20261112/independent-agent-review.json) شکست اولیه را حفظ کرده است. این بازبین یک عامل هوش مصنوعی بود، نه داور مستقل انسانی.

## بازتولید و اولویت بعد

از ریشهٔ مخزن، با Python و بدون API:

```bash
python -m unittest discover -s examples/dios_nous -v
python -m examples.dios_nous cognitive-demo
python -m examples.dios_nous.evaluate_work --split dev --output dios-dev-new.json
python -m examples.dios_nous.evaluate_work --split holdout --output dios-holdout-regression-new.json
```

فایل خروجی ارزیاب باید تازه باشد؛ نتیجهٔ قبلی بازنویسی نمی‌شود. برای نگه‌داشتن فایل‌های نمونه، به `cognitive-demo` گزینهٔ `--output-dir` با پوشهٔ خالی بدهید.

اولویت بعد، تعریف و آزمون یک مرز معتبر برای احراز منبع و مجوزِ محدود، همراه انقضا، ابطال و رسید است؛ تا آن زمان هیچ اتصال اجرایی توصیه نمی‌شود. پس از آن، ارزیابی تازه با داده و داوری انسانی جدا و خط مبنای هم‌قدرت لازم است. کد اجرا شد و آزمون‌ها نتیجه دادند؛ این شواهد اثبات آگاهی، تجربهٔ ذهنی یا قضاوت عمومی نیستند.
