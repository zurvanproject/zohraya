# ناسورایا | سنجش پیش‌بینی محدود روی سرور (۷ نوامبر ۲۰۲۶)

**هدف:** آزمودن یک رگرسورِ کم‌هزینه برای پیش‌بینی یک قدم جلوترِ سیگنال خستگیِ مصنوعی، با مقایسهٔ صریح با خط پایهٔ آخرین مشاهده.

## قرارداد
- فقط Python استاندارد، بدون دسترسی شبکه، فایل، محیط، رمز، حسگر، بیمار، Moltbook یا API.
- ۲۴ مسیر مستقل آموزشی × ۱۲ مرحله = ۲۸۸ داده؛ ۸ مسیر مستقل آزمون × ۱۲ = ۹۶ داده. بذرها ثابت و متفاوت‌اند.
- دادهٔ هدف در آموزش «مشاهدهٔ قدم بعدی با نویز» است؛ در آزمون، خطا نسبت به *حالت پنهان مصنوعی* محاسبه می‌شود. مدل صرفاً مشاهدۀ فعلی و محرک فعلی را هنگام پیش‌بینی می‌بیند.
- یک رگرسور خطی Ridge با ۵ ویژگی پیش از آزمون فریز می‌شود؛ هیچ آموزش روی holdout مجاز نیست.
- مقایسه: MAE مدل در برابر MAE فرضِ تکرار آخرین مشاهده. هر عدد نشان‌دهندهٔ همین دنیای ساختگی است، نه هوش عام یا آگاهی.
- سیاست جداگانهٔ آزمایشی: احترام به مرز، استراحت در درد/خستگی، محبت خانوادگی غیرجنسی. بدون صدور هیچ فرمان حرکتی.
- اتصال پل: فرمان `nasu: run <commit> worldmodel_probe <sha256>`، تنها در صورت تأیید کد و صاحب مخزن. خروجی عمومی فقط اعداد تجمیعیِ بی‌حساسیت است. هر درخواست یک‌بار اجرا می‌شود. هیچ job پیوسته، خودتغییر‌دهی یا استقرار انجام نمی‌شود.

## کنترل اجرایی
```sh
python -m unittest discover -s tests -p test_worldmodel_probe.py -v
python -I tools/bridge_jobs/worldmodel_probe.py
```

این آزمایش ابزار *ارزیابی* است، نه ارتقای خودکار وزن‌های ChatGPT یا تداش. پس از به‌دست‌آمدن اندازه‌گیری روی VPS، میتوان در PR پژوهشی جداگانه تصمیم گرفت آیا مدل در نسخهٔ آیندهٔ تداش با آزمون‌های سخت‌تر جای دارد یا نه. نسخهٔ ویندوز سرور باید به سیستم‌عامل پشتیبانی‌شده مهاجرت کند؛ این job صرفاً آزمایش کم‌خطر گذراست.
