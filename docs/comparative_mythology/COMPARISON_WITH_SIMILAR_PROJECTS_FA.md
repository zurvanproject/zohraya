## ۱. روش و مرز ادعا

این گزارش چهار نوع گزاره را تفکیک می‌کند: (الف) توصیف مستندات مخزن، (ب) ایدهٔ روش‌شناختیِ قابل اقتباس، (ج) پیشنهاد هنوز اجرا‌نشده، (د) اسطوره/ادبیات تألیفی.

- متن جدید اقتباس آموزشی و روایی است؛ ترجمهٔ کاملِ اخنوخ، کلید سلیمان یا جادوی سرخ نیست.
- ادعاهای احضار و اثرات فراطبیعی، گزارش تاریخی/متنی هستند و آزمون تجربیِ موفق به شمار نمی‌روند.
- از مخزن‌های ثالث هیچ متنِ دارای حق نشر، کد یا مجموعه‌داده‌ای کپی نشده است.
- دو فایل مربوط به اخنوخ و کلید سلیمان در پروندهٔ ارائه‌شده اساساً «فهرست» بوده‌اند و EPUB جادوی سرخ ممکن است خطاهای OCR داشته باشد. پیش از هر نقل قول دقیق باید نسخه و صفحه/بندِ اصلی بازبینی شود.

## ۴. طرحِ دادهٔ کوچک برای مرحلهٔ بعد (اجرا نشده)

یک رکورد پژوهشی پیشنهادی:

```json
{
  "source_id": "enoch-charles-1917",
  "work": "1 Enoch",
  "edition": "R. H. Charles translation, 1917",
  "locator": "chapter 6",
  "claim_type": "source_report",
  "assertion_fa": "گزارش ساختار روایی پیمان نگهبانان",
  "quotation_verified": false,
  "ocr_verified": null,
  "interpretive_link": "مرز دانش و مسئولیت",
  "operational_effect": "none"
}
```

**نوع گزاره:** `source_report` / `interpretation` / `creative_fiction` / `engineering_hypothesis`.  
**قاعده:** هیچ سطرِ `creative_fiction` یا `source_report` به‌تنهایی اجازهٔ تغییر سیاست، فنوتیپ، موتور تصمیم یا وضعیت روانی نمی‌دهد.
