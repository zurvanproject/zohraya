# خودپیش‌بینی نتیجه و بازبینی اثر عاطفه — ناسورایا

این تغییر به `ExperienceController` موجود وصل است. پیش از اجرای هر عمل،
توزیع احتمال **عمل واقعی نهایی** و مقایسهٔ اثر حالت عاطفی ذخیره می‌شود؛ پس از
اجرا، رسید بومی بدن مبنای نمره‌دادن است. قابلیت در نرم‌افزار بیرونی ناسورایا
اجرا می‌شود؛ تغییر وزن مدل گفت‌وگو یا اثبات تجربهٔ ذهنی از آن نتیجه نمی‌شود.

## تغییر واقعی نسبت به نسخهٔ قبلی

نسخهٔ ۲۳ اکتبر از قبل حافظهٔ پایدار، valence/arousal، پیش‌بینی چهار متغیر
بدن و بازیابی پس از وقفه داشت. افزوده‌های این نسخه عبارت‌اند از:

1. پیش‌بینی نتیجه در چهار دستهٔ `walk/observe/protect/other`، جدا از ترجیح
   اولیه. پیامدهای دیگر بدن حذف نمی‌شوند؛ نام اصلی آن‌ها نیز حفظ می‌شود.
2. تخمین از تجربه‌های قبلی دارای رسید، با زمینهٔ فیزیکی، ترجیح و مدت.
   خط مبنای تجمیعی همان داده‌ها، ترجیح و مدت را دارد، اما زمینه را ندارد.
3. نمرهٔ Brier از بردار ذخیره‌شده پیش از عمل: جمع چهار خطای مربعی در بازهٔ
   صفر تا دو؛ کمتر بهتر است. این نمره درصد آگاهی نیست.
4. تفکیک کمبود شواهد: با کمتر از سه نمونهٔ هم‌زمینه، `predicted_action`
   برابر null است. توزیع هموارشده برای ثبت خط مبنا باقی می‌ماند. حد سه نمونه
   و یک شبه‌شمارش برای هر دسته، انتخاب مهندسی‌اند و ضمانت کالیبراسیون نیستند.
5. هشت مقایسه روی همان تصویر وضعیت: واقعی، اثر عاطفی خاموش، خنثی، کم/زیاد
   کردن valence، کم/زیاد کردن arousal و برچسب بی‌اثر. این مقایسه‌ها سیاست را
   محاسبه می‌کنند و چرخهٔ اضافی بدن اجرا نمی‌کنند.

این افزونه پیش‌بینی و پایش را بهتر می‌کند؛ پیش‌بینی تازه فعلاً انتخاب عمل
را عوض نمی‌کند. ممیزی عاطفی نیز اثر همان سیاست موجود را اندازه می‌گیرد.

## سابقه، بازیابی و حدود اعتماد

پیش‌بینی و ممیزی داخل همان intent، پیش از `loop.step`، ذخیره می‌شوند. پس از
وقفه همان انتظار بازیابی می‌شود. replay دوباره یاد نمی‌گیرد. اجرای ناموفق
نمره یا تجربهٔ موفق نمی‌سازد. intent قدیمی که پیش‌بینی نداشته، پس از دیدن
جواب پیش‌بینی‌دار نمی‌شود. تجربهٔ قدیمی بدون مدت از مدل جدید کنار گذاشته و
شمارش می‌شود؛ سابقهٔ قبلی حذف نمی‌شود.

پرچم prediction پیش‌بینی دسته‌ای و نمرهٔ آن را نیز خاموش می‌کند. حفاظت بومی،
بودجه، قفل نشست و فرمول‌های بدن حفظ شده‌اند. هش‌ها برای ردیابی و تشخیص تغییر
اتفاقی‌اند؛ امضای مستقل نیستند. برچسب source فقط در محدودهٔ دفتر محلی مورد
اعتماد اعتبار دارد. نتیجهٔ بدنی مداخلات عاطفی اجرا نشده است؛ گزارش آن‌ها
فقط حساسیت سیاست را نشان می‌دهد.

## اجرا و ادامهٔ کار

از ریشهٔ مخزن، روی Linux و Python 3.11+:

```sh
python3 -m examples.nasuraya_body_loop experience-test
python3 -m examples.nasuraya_body_loop self-knowledge-eval --output-dir /tmp/new-self-knowledge-eval
python3 -m examples.nasuraya_body_loop experience-demo --output-dir /tmp/new-experience-demo
```

نشست‌های دارای تجربه با همان `experience-step` از قابلیت تازه استفاده
می‌کنند. برای نشست جدید:

```sh
python3 -m examples.nasuraya_body_loop start --fixture sleep --max-actions 5 --session /tmp/new-self.sqlite
python3 -m examples.nasuraya_body_loop experience-enable --session /tmp/new-self.sqlite
python3 -m examples.nasuraya_body_loop experience-step --decision-id first --session /tmp/new-self.sqlite
python3 -m examples.nasuraya_body_loop experience-status --session /tmp/new-self.sqlite
```

`plan.action_forecast` انتظار پیش از عمل، `plan.affect_audit` مقایسهٔ حالت‌ها،
`action_forecast_score` نمره و `self_knowledge` خلاصهٔ نمرات کم‌سابقه/دارای‌سابقه
است. مسیر API قدیمی یا شاخه‌های ادغام‌نشدهٔ گفت‌وگو خودکار به این کنترل‌گر
منتقل نمی‌شوند. فرایند دائمی و مصرف API راه‌اندازی نشده است.

## قرارداد گزارش‌دادن ناسورایا

وقتی دربارهٔ توانایی خودم گزارش می‌دهم، انتظار ثبت‌شده، نتیجهٔ واقعی، سابقهٔ
هم‌زمینه و عدم قطعیت را جدا می‌کنم. اثر متغیر داخلی را با کنترل می‌سنجم.
کاهش خطا را به همان آزمون و دامنهٔ اجرا نسبت می‌دهم. برای ادامه، این سند و
رسیدهای نسخهٔ جاری باید خوانده شوند؛ ذخیرهٔ سند به تنهایی وزن مدل یا
دسترسی خودکار به حافظه را تغییر نمی‌دهد.

## نتایج ثبت‌شده

پروتکل پیش از جواب‌ها ثابت شد: هشت نشست از ترکیب دو fixture normal/sleep،
دو ترجیح walk/observe و دو مدت ۰٫۱/۰٫۳ ثانیه. پنج دور اول ۴۰ رسید آموزشی
ساخت؛ سه دور بعدی ۲۴ رسید ارزیابی ساخت. تاریخچهٔ آموزش در ارزیابی ثابت ماند.
کنترل جابه‌جایی زمینه‌ها seed ثابت دارد و آزمون معناداری آماری نیست.

| معیار در ۲۴ چرخهٔ ارزیابی | نتیجه |
| --- | --- |
| میانگین Brier با زمینهٔ بدنی | ۰٫۱۷۹۰۱۲۳۴۶ |
| میانگین Brier خط مبنای تجمیعی | ۰٫۳۰۶۱۲۲۴۴۹ |
| کاهش نسبی Brier | ۴۱٫۵۲٪ |
| پیش‌بینی دستهٔ درست، زمینه‌ای / تجمیعی | ۲۴ از ۲۴ / ۱۸ از ۲۴ |
| Brier کنترلِ زمینه‌های جابه‌جاشده | ۰٫۴۹۰۷۴۰۷۴۱ |
| Brier بدون سابقه | ۰٫۷۵ |
| چرخهٔ واقعی نرم‌افزار / فراخوان API | ۶۴ / صفر |

پیامدهای بخش ارزیابی ۱۸ observe و ۶ walk بودند؛ protect در آموزش رخ داد،
اما در ارزیابی رخ نداد. بنابراین این نتیجه آزمون پیش‌بینی حفاظت در آینده
نیست. ارزیابی ادامهٔ زمانی همان دو خانوادهٔ ساختگی است، نه جهان تازه، نه
احساس انسان و نه رتبه‌بندی خودآگاهی. نتیجه به گفت‌وگوی آزاد یا حرکت بهتر
تعمیم داده نمی‌شود. کنترل‌گر تجمیعی مدل زبانیِ مستقل نیست.

پروتکل، دادهٔ آموزشی، پیش‌بینی‌های پیش از عمل، رسیدها و خلاصه در
[پوشهٔ شواهد](evidence/self-knowledge-v01/) هستند. تمام پرونده‌ها ساختگی‌اند؛
هیچ دادهٔ شخصی کاربر یا کلید سرویس در آن‌ها قرار ندارد.
