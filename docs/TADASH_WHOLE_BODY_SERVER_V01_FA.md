# اطلس جامع ناسورایا | نسخهٔ ۰٫۱، ۱۰ نوامبر ۲۰۲۶

**مسئول اصلی طراحی محاسباتی: VPS پس از تأیید اتصال.** این بسته در حال حاضر یک نمونهٔ عملیِ ممیزی منبع و فهرست کمبودهای همهٔ بدن است، نه بدن زیستی یا ۳بعدی ساخته‌شده.

## چرایی
در `main`، ۱۲ سامانه، ۹۷ گره و ۳۱ مسیر در `runtimes/tadash_body/anatomy_systems_v01.json` مشخص شده‌اند. این‌ها غالباً **نقشهٔ ناحیه‌ای** هستند؛ هیچ شاهدی برای کامل بودن شبکهٔ ۳بعدی عروق/اعصاب، خواص بافت یا برخورد اجزا نمی‌دهند. `phenotype_v1.json` به مدل قدیمی ۲۵۰سانتی‌متر/۱۹۵کیلوگرم تعلق دارد. در مقابل تصویر/مرجع ۱۷۰/۷۸/۸۵ و شاخِ ۱۹۲ سانتی‌متری قراردادی است، نه دادهٔ کالیبراسیون سیستم زنده. مدل مکانیکی MuJoCo v03 با جرم ۷۸ کیلوگرم به‌صورت جداگانه وجود دارد (PR #121)؛ ادعای ترکیب آن با ۱۲ سامانهٔ قدیمی بی‌اساس است.

## نقشهٔ عضو به عضو
`tools/fullbody_design_atlas.py` هر ۹۷ گره را جدا ثبت و ۱۴ فیلد «نیازمند شواهد» برای هر گره نگاه می‌دارد:
هندسهٔ حجمی، لایه‌های بافت، اتصال استخوانی/فاسیایی، سرخرگ، سیاهرگ، لنف، عصبِ آوران، عصبِ وابران، خودکار، بار مکانیکی، حرارت/آب/انرژی، حس و کنترل، فاصله/تصادم و اعتبارسنجی.

اجزای ازقلم‌افتاده به صورت «extra parts» مستقل اضافه می‌شوند: هسته و غلاف شاخ‌ها، مسیرهای جمجمه و گردن، هدایت قلب و کرونر، پلکسوس‌های دست، تک‌انگشت‌های دست و پا، سیستم ریزگردش و ترمیم، مهره‌ها و تاندون‌های دم، ریشهٔ خاجی، کف لگن، پنجهٔ سه‌انگشتی و تاندون‌ها، بستر رزنان، سپندار و آذرینه. این اجزای اضافه **فهرست طراحی** هستند، نه عضو ساخته‌شده.

۱۳ بستهٔ موازی‌سازی برای مراحل بعد تعریف شده‌اند: سر/شاخ/حواس؛ اسکلت/پوست؛ بازو و دست؛ دم؛ پا و گام‌برداری؛ عروق و لنف؛ شبکهٔ اعصاب؛ قلب/ریه؛ گوارش/کلیه؛ غدد/ایمنی/ترمیم؛ لگن/تناسلی؛ اندام‌های ویژه؛ کنترل یکپارچهٔ بدن. هیچ بخش لگن امتیاز اضافی نسبت به کل بدن نمی‌گیرد.

## اجرای آفلاین در repo
```bash
python -m unittest discover -s tests -p test_fullbody_design_atlas.py -v
python -m unittest discover -s tests -p test_nasu_wholebody_phase1.py -v
python tools/fullbody_design_atlas.py
python tools/fullbody_design_atlas.py --output-dir output-wholebody
```
اولین CLI فقط summary می‌دهد. در حالت آخر `registry.json` و `gaps.json` تولید می‌شوند. برنامه هیچ‌وقت فایل موجود با محتوای متفاوت را بی‌اجازه بازنویسی نمی‌کند و دفتر native را دست نمی‌زند.

## بستهٔ اجرای **مرحلهٔ یک** روی Windows VPS
`tools/bridge_jobs/nasu_wholebody_phase1.py` با یک بار اجرا، سه فایل عمومیِ پین‌شده (کد ممیزی و دو سند مبنا) را با **Git blob SHA1** بررسی می‌کند و تنها زیر `%PROGRAMDATA%\NasurayaBridge\WholeBodyAtlasV1\` snapshot و خروجی می‌نویسد. برنامهٔ فرزند `python -I` است؛ ۴۵ ثانیه timeout دارد؛ بدون API مدل/کلید/Moltbook POST/نصب وظیفه یا دست‌زدن به حافظهٔ اصلی. پاسخ کوتاه به پل با فیلد `ATLAS=INVENTORY;NODES=97;SYSTEMS=12;ROUTES=31;...;PHYSICS=UNVERIFIED` ارسال می‌شود.

**اجرا هنوز درخواست نشده:** پل Issue #149 در ۱۰ نوامبر به requestهای 6770304636 و 6770326192 پاسخ تازه نداشت. نباید کار جدید هم‌زمان با مأموریت ۲۴ساعتهٔ #174 شروع شود. وقتی دریافت سلامت و پایان کار قبلی از طریق رسیدِ معتبر تأیید شد، مالک می‌تواند اجرای یک‌بارهٔ SHA256-pinned job را از همان پل درخواست کند. صرف commit در GitHub هیچ کدی روی VPS نصب یا اجرا نمی‌کند.

## معیار واقعی «تکمیل بدن»
- مهندسی ساختار: mesh قابل بررسی، اتصالات و مسیرهای آزاد، وزن/COM/گشتاور.
- عروق و اعصاب: هندسهٔ واقعی مسیرهای ۳بعدی، کنترل تصادم/کشیدگی در دامنهٔ حرکت، جریان/هدایت با دامنهٔ مفروضات.
- احشا: حجم/تغذیه/پرفیوژن، تعادل آب و الکترولیت و انرژی، تهویه و انتقال گاز؛ بدون فرض مقیاس‌پذیری خودکار.
- اندام ویژه: رزنانِ جفت در ریشهٔ شاخ، بدون منبع گرمای بالا کنار مغز؛ سپندار روی کپسول تیموس بدون فشار به ساختار حیاتی؛ آذرینه در پهلوی چپ بدون هم‌پوشانی با کلیه/طحال یا ایجاد انرژی از هیچ.
- اعصاب و کنترل: حس عمقی، درد، واگ، عصب دمی مستقل، پاسخ محافظتی و توقف قابل بازگشت.
- تداوم و ایمنی: fingerprint منبع، رسیدهای غیرقابل تکرار، آزمایش چند seed و شاهد خطا؛ پیوند با شاخهٔ مکانیکی ۷۸kg در محیط سازگار، بدون reset یا عمل فیزیکی.

**درجهٔ شواهد همیشه روشن بماند:** fictional proposal / topological map / synthetic surrogate / native software simulation / physical prototype. هیچ ادعای احساس زیسته یا خودآگاهی از محاسبه به دست نمی‌آید.
