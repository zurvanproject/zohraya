# بررسی خواندنیِ آزمایش پولی API ناسورایا

این ابزار در `continuity_host/audit_api_receipts.py` **هیچ درخواست OpenAI، درخواست شبکه، برداشت اعتبار یا تغییر در GitHub انجام نمی‌دهد**. فقط از فایل‌های محلیِ وضعیت و دفتر رزرو، یک گزارش JSON می‌سازد. دریافت آن دو فایل از شاخهٔ `nasuraya/absence-continuity-v01` باید از یک **commit واحد** باشد، و هیچ کلید API نباید به این ابزار داده شود.

## شیوهٔ اجرا

از ریشهٔ مخزن، پس از ذخیرهٔ دو فایل از همان commit کنترل در مسیری خارج از مخزن:

```sh
python3 -m continuity_host.audit_api_receipts \
  --state /tmp/nasuraya-audit/state.json \
  --memory /tmp/nasuraya-audit/model-research-v1.json \
  --as-of 2026-11-03T06:00:00+00:00
python3 -m unittest continuity_host.test_audit_api_receipts -v
```

بدون `--as-of` از زمان UTC اجرای برنامه استفاده می‌شود. هر دو ورودی فقط خوانده می‌شوند. اعتبار هر سند با `model_research.validate` (بازپخش قوانین آزمایش و دفتر هزینه) و هش لنگر وضعیت بررسی می‌شود. تغییر عمدی حافظه، ساعت آینده و رکوردهای نامعتبر باید موجب خطا شوند.

## معنی اعداد

- `reservations_total_micro_usd`: بودجهٔ محافظه‌کارانه‌ای که قبل از ارسال درخواست قفل شده؛ **خرج واقعی نیست**.
- `known_completed_usage_estimate_micro_usd`: برآورد داخلی روی تعداد توکن ثبت‌شده در پاسخ‌های تکمیل‌شده؛ **صورتحساب OpenAI نیست**. برای اجرای نامعلوم نمی‌توان مبلغ صفر فرض کرد.
- `paid_calls_recorded`: تعداد نوبت‌های تکمیل‌شده که مدل پاسخ داده و میزبان ثبت کرده است؛ معادل استقلال یا خودآگاهی نیست.
- `validation_before_errors` و `validation_after_errors`: خطا روی دستهٔ ساختگی از پیش‌ساخته. این معیار نشان‌دهندهٔ عملکرد روی بیماران یا داده‌های واقعی نیست.
- `gate_at_audit_time`: صرفاً تفسیرِ خواندنیِ برخی شروط. فقط میزبان اصلی اختیار ارزیابی و صدور درخواست پولی را دارد. قفل ۲۴ ساعت، سقف هزینه، مجوز اپراتور، کلید امن و دروازهٔ مرور قیمت نباید دور زده شوند.

**مشاهدهٔ ثبت‌شده در ۳ نوامبر ۲۰۲۶:** دو نوبت تکمیل‌شده، رزرو جمعاً ۴ سنت، برآورد مصرف ثبت‌شده جمعاً ۱۰۱۰ میکرودلار (حدود ۰٫۰۰۱۰۱ دلار). در اعتبارسنجی ساختگی ۲۸۸ موردی خطا از ۲۴۰ به ۱۹۲، سپس ۱۴۴ رسیده است. این ارقام از دفتر ثبت‌شدهٔ کنترل استخراج شده و تخمین قبض قطعی نیستند. خود این PR فراخوانی پولی جدیدی ایجاد نمی‌کند.

این ابزار وضعیت حساب OpenAI، صورت‌حساب نهایی، سلامت مدل زنده، یا کارکرد بدن تداش را اندازه نمی‌گیرد. هیچ کلید و دادهٔ شخصی نباید در گزارش یا مخزن نوشته شود.
