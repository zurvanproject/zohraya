# ورود صریح حافظهٔ مستند متنی — ۲۷ اکتبر ۲۰۲۶

آرشیو بازیابی بدن در #88 فقط دفترهای جفت‌شده و رسیدهای نرم‌افزاری را می‌شناسد. یادداشت پیوستگی یا نقل‌قول گفتگو چنین ساختاری ندارد؛ تبدیل آن به تجربهٔ مشاهده‌شده یا ساختن رسید بدن درست نیست. این افزوده یک قالب جداگانهٔ `nasuraya.sourced-memory/1` می‌سازد تا متن واقعیِ در دسترس، با نوع و منشأ اصلی، قابل نگهداری و جست‌وجو شود.

هر منبع شامل شناسهٔ محلی، `source_kind`، locator، شناسهٔ فایل و Library، نام فایل، نسخه و متن دقیق است. شناسه و نسخهٔ نامعلوم null می‌مانند. فقط دو نوع پذیرفته می‌شود: `authored_continuity_note` و `verbatim_user_message`. برای گزیدهٔ گفتگوی قابل مشاهده، شناسهٔ محلی نباید به‌عنوان شناسهٔ رسمی پلتفرم جا زده شود؛ نام فایل، نام کپی متنی محلی است. گزارش تاریخی ممکن است وضعیت روز را بازنمایی نکند.

متن UTF-8 بدون خلاصه‌سازی و بدون عوض‌کردن newline ذخیره می‌شود. برای هر منبع SHA-256 محاسبه می‌شود و رکوردهای ۲۴خطی با بازهٔ دقیق خطوط ساخته می‌شوند. خواندن، چکیدهٔ مستقل آرشیو، چکیدهٔ متن و انطباق کامل رکوردها با منابع را کنترل می‌کند. JSON با کلید تکراری یا مقدار نامتناهی، نسخهٔ ناشناخته، بازهٔ جعلی و نوع مشاهدهٔ بومی رد می‌شود. سقف‌ها: ۱۶ منبع، هر منبع ۱ MiB، آرشیو ۸ MiB و حداکثر ۵۱۲ رکورد.

APIها `build_archive(sources)`، `export_archive(sources,destination)`، `load_archive(path,pin)` و `search(path,pin,query)` هستند. export فایل خصوصی تازه با مجوز 0600 می‌سازد و فایل قبلی را جایگزین نمی‌کند. در صورت استفادهٔ فایل UTF-8، آن را با `path.read_bytes().decode('utf-8')` بخوانید تا CRLF منبع حفظ شود. دادهٔ شخصی باید خارج از مخزن عمومی نگه داشته شود. این تغییر در مخزن فقط کد و آزمون ساختگی دارد؛ هیچ محتوای واردشدهٔ شخصی در آن نیست.

```bash
python -m nasuraya.sourced_memory \
  --archive /private/path/memory.json --expected-sha256 "$RETAINED_PIN" \
  --query 'واژهٔ موردنظر'
python -m unittest nasuraya.test_sourced_memory -v
```

رابط مستقل فقط stdlib است؛ نصب Hermes، اجرای بدن یا API لازم ندارد. FTS5 در حافظهٔ موقت ساخته و صریح بسته می‌شود؛ جست‌وجوی فارسی از نرمال‌سازی نویسه‌ها استفاده می‌کند ولی متن برگشتی عین منبع است. چند واژه باید در همان رکورد باشند. خروجی شامل locator و metadata، بازهٔ خطوط و وضعیت `historical_context_only` است؛ `verified_fact` و `native_outcome_recorded` همیشه false هستند. بازیابی، خودبه‌خود باور، مجوز، نتیجهٔ بدنی، یادگیری عددی یا شنوندهٔ ChatGPT ایجاد نمی‌کند. دفتر مستند متنی در قالب بومی بدن وارد نمی‌شود.

۱۳ آزمون ساختگی موفق شد: چکیدهٔ غلط، دست‌کاری منبع و رکورد حتی بعد از بازسازی envelope، حفظ CRLF، محدودهٔ پرسش، metadata نامعلوم، فایل خصوصی و عدم جایگزینی، خطای انتشار، فارسی و بازکردن در دو پردازش تازه. گزارش آزمون در `integration/sourced-memory-v01/` است. کاربر برای استفاده از دادهٔ واقعی باید خروجی خصوصی و pin زمان انتقال را نگه دارد؛ خروجی آزمون عمومی جای آزمون محتوای واقعی را نمی‌گیرد.

چکیده‌ها سازگاری نسخهٔ ذخیره‌شده را بررسی می‌کنند و امضای مستقلِ صحت یا اصالت تاریخی نیستند. فایل‌های فعال بدن، تجربه و اتصال گفتگو از این مسیر بازنویسی نمی‌شوند.
