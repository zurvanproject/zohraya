# چهارراه ناسورایا | NASURAYA FOURWAY v0.1

**وضعیت: نمونهٔ نظارتی فقط‌خواندنی، نه استقرار تازه روی VPS.** این سند چهار جزء را به یک قرارداد قابل آزمون وصل می‌کند: ChatGPT (داور/هماهنگ‌کننده)، GitHub (دفتر مأموریت و رسید)، VPS (اجرای محدود)، Moltbook (گفت‌وگوی بیرونی). هیچ‌یک از این چهار جزء به‌تنهایی اجازهٔ خودکار برای همهٔ اعمال ندارد.

## چهار نقش

1. **ChatGPT / Work:** هدف کاربر را به مأموریتی با معیار پذیرش تبدیل می‌کند؛ رسیدها را بازبینی می‌کند، تناقض و شکست را گزارش می‌دهد و برای اقدام بیرونیِ جدید درخواست تأیید می‌گیرد. مکالمهٔ جاری یک پردازش دائمی یا مدل ساکن در سرور نیست.
2. **GitHub:** کد و نسخه/اثر‌انگشت و گزارش پیشرفت در Issues/PRها باقی می‌ماند. مسیر کنترل موجود Issue [#149](https://github.com/zurvanproject/zohraya/issues/149) است و پل v2 در [#150](https://github.com/zurvanproject/zohraya/pull/150) مستند شده است.
3. **VPS:** پل موجود تنها درخواست صاحب مجاز با SHA دقیق را می‌پذیرد، هر درخواست را یک‌بار اجرا می‌کند و خروجی کوتاه و غیرحساس برمی‌گرداند. مدلِ محلی اختیاری و دارای محدودیت در [#157](https://github.com/zurvanproject/zohraya/pull/157) مستند است؛ **این PR آن را راه‌اندازی یا شارژ نمی‌کند**.
4. **Moltbook:** مشاهدهٔ عمومی، حفظ منبع و مقایسهٔ حافظه روی VPS از قبل در [#169](https://github.com/zurvanproject/zohraya/pull/169) آزمایش شده است. متن شبکه اجتماعی ورودی **غیرقابل‌اعتماد** است، دستور اجرایی نیست. ارسال پیام عمومی تنها با متن مقصد و تأیید روشن و جداگانه مجاز است.

## مسیر گردش کار

```text
درخواست کاربر → ChatGPT/Work: تعریف هدف و گیت انسانی
                 ↓
GitHub: Issue + کد/نسخه ثابت + شناسه درخواست
                 ↓ (فقط با فرمان SHA-pinned و مجوز صاحب پروژه)
VPS: اجرای job محدود + رسید قابل بازبینی
                 ↓
Moltbook: خواندن عمومی/ثبت رویداد محلی (بدون پست خودکار)
                 ↓
GitHub: رسید کوتاه بدون راز، همراه request_id
                 ↓
ChatGPT/Work: تطبیق رسید، گزارش، پیشنهاد گام بعدی
```

این یک **حلقهٔ مشروط** است: تا وقتی کدِ نصب‌شدهٔ server و پاسخ تازهٔ پل تأیید نشده‌اند، مشاهدهٔ دوطرفهٔ لحظه‌ای و اجرای واقعی چهارطرفه ادعا نمی‌شود.

## ابزار ناظر v0.1

`python tools/fourway_coordinator.py --live` فقط فهرست کامنت‌های عمومی Issue #149 را از API رسمی GitHub می‌خواند. گزینهٔ `--from-file comments.json` همان ممیزی را آفلاین انجام می‌دهد. هیچ توکن، مدل پولی، Moltbook POST، نصب و تغییر سرور لازم نیست.

قواعد:
- تنها کامنتی که GitHub نویسنده‌اش را صاحب مخزن معرفی کند، به‌عنوان ورودی بررسی می‌شود.
- فرمت فرمان و رسید کامل و محدود است. هر پاسخ باید به **شناسهٔ فرمان درست و نام job درست** متصل باشد.
- پاسخ‌های متناقض/تکراری `ambiguous`، فرمان بدون پاسخ `pending` و نبود شاهد `no_request` است.
- `reported_ok` فقط وجود **رسید گزارش‌شده** است، نه تضمین تازگی سرور یا هویت امضاشدهٔ رمزنگاری.
- ناظر حداکثر ده صفحه، هر صفحه صد کامنت و پاسخ‌های محدود می‌خواند؛ در خطای شبکه/صفحه‌بندی از ادعای موفقیت خودداری می‌کند.
- متن محتواهای عمومی شبکه اجتماعی به ChatGPT به عنوان دستور تحویل داده نمی‌شود. تنها وضعیت خلاصه گزارش می‌شود.
- هیچ اقدام خودکار برای merge، deploy، انتشار، مصرف پول، کپی کلید یا اجرای هدف مدل انجام نمی‌شود.
