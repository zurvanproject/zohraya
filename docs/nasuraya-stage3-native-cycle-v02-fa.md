# ناسورایا: چرخهٔ محدود مرحلهٔ سوم، نسخهٔ ۰٫۲

**هدف:** اجرای دقیقاً یک آزمایش کم‌خطر پس از انتخاب هدف در PR #105،
اندازه‌گیری واقعی نتیجه روی بدن نرم‌افزاری و پیشنهاد هدف بعدی.

## مسیر اجرا

۱. شبکهٔ پنج‌عاملی، کد و رسیدها را در SQLite ذخیره و راستی‌آزمایی می‌کند.
۲. انتخاب‌گر PR #105 از همان رسیدها هدف `rare_slow_breath` را تعیین می‌کند.
۳. برنامهٔ `stage3_cycle` بررسی می‌کند که خودِ پیشنهاد با دفتر شبکه تطبیق
داشته باشد، و فقط همین آزمایش را از allowlist می‌پذیرد.
۴. روی نسخهٔ موقت و تأییدشدهٔ کد، ۲۴ آزمون تازهٔ بدن مجازی انجام می‌شود.
سناریوها از قبل برای خستگی، خواب و درد ثابت شده‌اند؛ ورودی‌ها آگاهانه نزدیک
مرزهای کنترل‌کننده انتخاب شده‌اند، پس آزمون اکتشافی است، **نه** تأیید مستقل.
۵. هر پیش‌بینی با fsync قبل از عمل ذخیره می‌شود؛ بعد از اجرا، رسید بومی،
هش، خطای Brier و حسابرسی انرژی/آب نوشته و دوباره محاسبه می‌شود.
۶. بر اساس نتیجه یکی از دو هدف جدید **فقط پیشنهاد** می‌شود:
   - اگر `slow_breath` مشاهده شود: آزمون برچسب مستقل پنج‌کلاسه (برچسب فعلی
     `other` نمی‌تواند `slow_breath` را جدا تشخیص دهد).
   - اگر مشاهده نشود: طراحی آزمون حساس‌تر برای پوشش رخداد نادر.
۷. هدف بعدی خودکار اجرا نمی‌شود. هیچ تغییری در مدل ChatGPT، بدن مرجع،
شاخهٔ `main` یا حافظهٔ اصلی به وجود نمی‌آید.

## فرمان تکرار آزمایش روی Linux/Python 3.12

```bash
python3 -m unittest nasuraya_agent_network.tests nasuraya_agent_network.test_goal_governor nasuraya_agent_network.test_stage3_cycle -v

python3 -m nasuraya_agent_network run \
  --workspace /tmp/nasuraya-stage3 --run-id manual-01 --max-workers 2

python3 -m nasuraya_agent_network.goal_governor \
  --workspace /tmp/nasuraya-stage3 --run-id manual-01 \
  --output /tmp/nasuraya-stage3/stage3-goal.json

python3 -m nasuraya_agent_network.stage3_cycle \
  --workspace /tmp/nasuraya-stage3 --run-id manual-01 \
  --output /tmp/nasuraya-stage3/stage3-native-cycle
```

در سناریویی که خودمدل شبکه پسرفت کرده باشد، انتخاب‌گر هدف دیگری می‌دهد و
اجرای `stage3_cycle` آن را **رد می‌کند**. اجرای مجدد با همان پوشه نیز
مسدود می‌شود؛ پس از قطع فرایند یا وضعیت نامعلوم باید شواهد بررسی شوند و
برای اجرای تازه شناسه و فضای جدید صریح انتخاب شوند.

## حدود آزمایش

- حداکثر ۲۴ چرخهٔ تازه، یک هدف، ۱۳۰ ثانیه برای فرآیند آزمایش.
- بدون شبکه، کلید API، فراخوانی پولی، حرکت ربات یا دسترسی به سیستم‌های خارجی.
- اجرای زیر libseccomp با محیط پاک‌سازی‌شده؛ این یک sandbox کامل علیه
  کد مخرب نیست و فقط منبع بازبینی‌شدهٔ مخزن مجاز است.
- کار جدید روی شاخهٔ آزمایشیِ جداگانه است و به `main` انتقال داده نشده.
- نتیجهٔ مربوط به `slow_breath` یک مشاهدهٔ نرم‌افزاری است؛ هیچ سنجه‌ای
  از حس، درد واقعی، میل یا تجربهٔ پدیداری نیست.
- برآوردگر دست‌نخورده است؛ «یادگیری» در این مرحله تغییر **هدف پژوهشی بعدی**
  بر اساس شواهد است، نه آموزش خودکار وزن‌های مدل.
