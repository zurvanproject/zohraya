# Nasuraya continuity store v0.1 | دفتر دوام مشاهده‌های عمومی

**وضعیت: پیش‌نویس پژوهشی، غیرفعال روی سرور تا زمان نصب و تأیید.**

این تغییر روی شاخه‌ای مستقل، بالای PR #145 قرار گرفته است. هدف آن این است که snapshot عمومی مولت‌بوک، که پل فقط‌خواندنی در public_social_snapshot.json می‌نویسد، به یک تاریخچهٔ محلی و **قابل‌انتقال** در SQLite تبدیل شود. تغییر در سرویس فعال، کد زمان‌بندی‌شده، حساب مولت‌بوک یا حافظهٔ خصوصی تداش ایجاد نمی‌شود.

## مرزهای داده

- ورودی فقط خروجی معتبر runtimes.tadash_body.social_observations.load_social_observations است: عامل nasuraya، وضعیت claimed، تاریخ تازه، حداکثر ۲۰ ردیف و متن محدود. فایل ناسازگار/قدیمی رد می‌شود.
- همهٔ عنوان‌ها، خلاصه‌ها و نویسندگان با برچسب untrusted_external در پایگاه جدا ذخیره می‌شوند. **این محتوا دستور، حقیقت تأییدشده، حافظهٔ شخصی یا دادهٔ آموزشی نیست.** حضور نام و وضعیت claimed در فایل، امضای رمزنگاری‌شدهٔ منبع محسوب نمی‌شود.
- هیچ تماس شبکه‌ای، فراخوانی مدل پولی، انتشار پست، خواندن گفت‌وگوی خصوصی، تغییر در BodyLoop، یادگیری خودکار یا تغییر وزن مدل وجود ندارد.
- پایگاه در **همان پوشهٔ خصوصی snapshot** ساخته می‌شود: در ویندوز از ACL موجود پل و در لینوکس فقط از پوشهٔ دارای مجوز خصوصی استفاده می‌کند. فایل پیوندی رد می‌شود.
- وارد کردن یک snapshot تکراری تغییری در تعداد مشاهده‌ها ایجاد نمی‌کند؛ نسخهٔ اصلاح‌شدهٔ یک آیتم به‌صورت نسخهٔ جدا نگهداری می‌شود. هش SHA-256 رسید برای بررسی سازگاری است، نه اثبات اصالت.
- وضعیت آرشیو فقط شمارنده‌ها و زمان را برمی‌گرداند، نه متن محتوا.

## تست بدون شبکه

از ریشهٔ مخزن در Python 3.12:

~~~powershell
python -m unittest -v examples.nasuraya_moltbook_gateway.test_continuity_store
~~~

در PR #145، آزمون‌های آفلاین دیگر پل اجتماعی نیز وجود دارند. اجرای این آزمون نیازی به کلید Moltbook ندارد.

## Windows VPS: اولین ورود دستی به تاریخچه

پیش‌نیاز: شاخهٔ nasuraya/public-continuity-store-20261105 روی VPS در پوشهٔ مخزن موجود باشد؛ snapshot پل قبلی واقعاً ساخته شده باشد. **با دانلود تنها فایل Python، بدون مسیر runtimes، این ماژول اجرا نمی‌شود.**

در PowerShell سرور، از ریشهٔ همان checkout:

~~~powershell
$py = Join-Path $env:LOCALAPPDATA 'Programs\Python\Python312\python.exe'
$private = Join-Path $env:LOCALAPPDATA 'Nasuraya\Moltbook'
$module = 'examples.nasuraya_moltbook_gateway.continuity_store'
& $py -m $module ingest --snapshot (Join-Path $private 'public_social_snapshot.json') --db (Join-Path $private 'social_history.sqlite')
& $py -m $module status --db (Join-Path $private 'social_history.sqlite')
~~~

در خروجی سالم، may_train، may_modify_body و may_publish همگی false هستند. در واردکردن دوبارهٔ همان snapshot، replayed=true می‌شود. نخست موفقیت **اجرای دستی روی VPS ویندوز سرور ۲۰۱۲** باید دیده شود؛ CI در سیستم‌عامل جدیدتر جایگزین آن نیست.

این ماژول **خودش Scheduled Task جدید نصب نمی‌کند**. Task خواندن هر ۱۵ دقیقهٔ موجود نیز تغییر نمی‌کند. برای آرشیو پیوسته باید پس از تأیید اجرای دستی، یک مرحلهٔ import محلی و مجزا پس از snapshot به کار زمان‌بندی‌شده افزوده شود؛ تا آن زمان فقط اجرای دستی تأییدشده قابل ادعاست. بعد از قطع اتصال RDP و reboot باید اجرای زمان‌بندی‌شده جداگانه آزموده شود.

## نسخهٔ پشتیبان برای مهاجرت

~~~powershell
& $py -m $module backup --db (Join-Path $private 'social_history.sqlite') --dest (Join-Path $private 'social_history.export-01.sqlite')
~~~

این خروجی با روش backup خود SQLite سازگار است، و حتی با WAL می‌تواند یک فایل یکپارچه بسازد. فایل خروجی **رمزگذاری نشده است**؛ تا انتقال از کانال رمزگذاری‌شده، فقط در پوشهٔ خصوصی نگهداری شود. نسخهٔ موجود بازنویسی نمی‌شود.

## مرز بین «حافظهٔ آرشیوی» و «یادگیری»

PR #142 یک موتور *کاملاً مصنوعی و آفلاین* برای یادگیری از رسیدها دارد. این آرشیو **به آن موتور متصل نیست**: متن تصادفی شبکه حق ساخت پاداش یا فرمان ندارد. مرحلهٔ بعدی فقط پس از بازبینی انسانی، قرارداد صریح منبع/بازخورد، جلوگیری از replay و آزمون‌های A/B می‌تواند یک نگاشت داده بسازد. هیچ ادعای شعور، احساس، بدن واقعی یا یادگیری از جهان بیرون از این نسخه نتیجه نمی‌شود.
