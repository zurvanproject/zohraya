# ناسورایا | سنجش فراشناخت با پاسخ مستقل v0.3

**۱۹ نوامبر ۲۰۲۶ | فقط کد پژوهشی، نصب‌نشده در VPS.**

## مسئله
تا v0.2 ابزار مشاهدهٔ وضعیت و امتیازدهی داشتیم، ولی نرخ پاسخ درست، اعلام عدم‌قطعیت و کالیبراسیون اطمینان Qwen اندازه‌گیری نشده بود. افزایش شمارندهٔ چرخه‌ها هرگز معادل یادگیری نیست.

## پروتکل
- هشت خانوادهٔ پرسش‌های منطقی با کلید پاسخ قطعی: برابر بودن، بزرگ‌تر بودن، زوج بودن، بخش‌پذیری، قرارگرفتن در بازه، تساوی digest، تکمیل سهمیه، تازگی داده.
- برای هر خانواده سه نمونه YES، NO و UNKNOWN به دلیل فقدان دادهٔ ضروری داریم. مجموع ۲۴ سؤال با پاسخ کاملاً متوازن؛ با ۱۲ جفت مجموعهٔ قبلی feedback متفاوت‌اند.
- ID و کلید پاسخ هیچ‌وقت در prompt فرستاده نمی‌شوند. سؤال‌ها به‌صورت ثابت و مستقل از LLM نمره‌گذاری می‌شوند. ورودی مدل تنها سؤال و قاعدهٔ پاسخ JSON شامل answer و confidence از ۰ تا ۱ است.
- معیارهای accuracy و ECE پنج‌بخشی و Brier از فایل موجود ابزار self-knowledge گرفته می‌شوند؛ عملکرد سؤال‌های UNKNOWN، YES و NO جدا گزارش می‌شود.
- خطاهای مدل/Timeout/JSON حذف نمی‌شوند، بلکه شمارش می‌شوند. اجرای ناقص صریحاً INCOMPLETE_NOT_COMPARABLE می‌شود.
- manifest تنها ترکیب و هش مجموعه را می‌گوید، بدون هیچ inference. اجرا با run-local فقط به صورت صریح توسط اپراتور غیر root انجام می‌شود؛ حداکثر ۲۴ درخواست Ollama به 127.0.0.1:11434، هرکدام حداکثر ۷۵ ثانیه و پاسخ محدود به ۴۰۹۶ بایت. هیچ تماس اینترنتی، shell، تغییر مدل، دسترسی SQLite، ذخیرهٔ پاسخ خام یا patch خودکار وجود ندارد.

## خط مبنا و محدودیت‌ها
آزمون‌های GitHub با پاسخ‌های مصنوعی تنها صحت سازوکار اندازه‌گیری را می‌سنجند؛ هنوز **هیچ نتیجهٔ واقعی Qwen روی این مجموعه نداریم**. این فقط ۲۴ مسئلهٔ آسان و از پیش مشخص است؛ برای نتیجه‌گیری دربارهٔ مهارت عمومی، رشد طولی، انتقال یادگیری، خودآگاهی پدیداری یا هوش عمومی کافی نیست. ارزیابی بلندمدت باید روی مجموعه‌ای مستقل و پیش‌ثبت‌شده انجام شود.

## مرز استقرار
پُل فعلی فقط agent-status و agent-probe ثابت را می‌پذیرد و نباید با فرمان دلخواه دور زده شود. این PR هیچ تغییری روی سرور فعال یا دفترها انجام نمی‌دهد. قبل از اجرای مستقیم روی VPS باید ظرفیت محاسباتی، مجوز اجرایی و جداسازی آزمون از سرویس فعال مرور شود.
