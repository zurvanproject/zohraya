# فرمان و پاسخ بدن — نسخهٔ نخست

معیار سهند در این مرحله، پاسخ عملی بدن به فرمان است: آگاهی از وضعیت مفصل‌ها، تماس پا و تعادل باید به حرکت قابل مشاهده کمک کند. این تغییر، به رابط فرمان و تداوم وضعیت بدن شبیه‌سازی‌شده اختصاص دارد.

## رفتار اجراشده

دو فرمان «یک قدم جلو برو و بایست» در دو فرایند جدا اجرا شدند. فرمان اول با پای چپ و فرمان دوم با پای راست انجام شد. فرمان دوم وضعیت نهایی فرمان اول را بازیابی کرد؛ وضعیت مفصل‌ها، سرعت‌ها، زمان و حالت انتگرال‌گیر در مرز دو فرمان دقیقاً یکسان بودند. هر دو فرمان در وضعیت متعادل پایان یافتند.

مدل، همان بدن مفصلی v03 با جرم ۷۸ کیلوگرم و ارتفاع تاج سر ۱٫۷۰ متر است. کنترل‌گر اصلی تماس، محدودیت گشتاور موتور و تنظیم هندسی تکیه‌گاه استفاده شدند. این کار کنترل‌گر آزمایشی شاخهٔ بهینه‌سازی را ارتقا یا تأیید نمی‌کند.

| نتیجه | مقدار اندازه‌گیری‌شده |
|---|---:|
| تعداد قدم پذیرفته‌شده | ۲، در دو فرمان جدا |
| زمان حرکت نمایش‌داده‌شده | ۲۲ ثانیه با سرعت واقعی |
| زمان آماده‌سازی فرمان دوم | صفر |
| جابه‌جایی خالص لگن در راستای جلو | حدود ۴٫۷۸ سانتی‌متر |
| بیشینهٔ انحراف تنه | حدود ۰٫۵۹ درجه |
| تماس غیر از پا / تجاوز از حد مفصل | هیچ / صفر |

پارامتر گام ۶ سانتی‌متر، هدف حرکت پا است؛ به معنی ۶ سانتی‌متر جابه‌جایی لگن در هر فرمان نیست. این حرکت آهسته است. بیشینهٔ استفاده از گشتاور موتور نزدیک سقف آن بود؛ از این اجرا نمی‌توان توان حمل بار یا حاشیهٔ توان اضافی نتیجه گرفت.

## رابط فرمان

`motion_commands.py` دو عبارت فارسی مشخص را می‌پذیرد: «یک قدم جلو برو و بایست» و «دو قدم جلو برو و بایست». این رابط، مفسر عمومی زبان یا شنوندهٔ خودکار چت نیست. هر فرمان در توقف پایدار پایان می‌یابد. شناسهٔ تکراریِ فرمان موفق، فقط رسید قبلی را برمی‌گرداند و بدن را دوباره حرکت نمی‌دهد. اجراهای ناقص یا ناموفق، نشست را برای بررسی متوقف می‌کنند.

نمونهٔ اجرا از ریشهٔ مخزن، با وابستگی‌های نصب‌شده:

```bash
export OPENBLAS_CORETYPE=Haswell
export OPENBLAS_NUM_THREADS=1
export OMP_NUM_THREADS=1
python -m examples.nasuraya_research.articulated.motion_commands start --session /tmp/nasuraya-demo-new --max-steps 2
python -m examples.nasuraya_research.articulated.motion_commands run --session /tmp/nasuraya-demo-new --id first --command 'یک قدم جلو برو و بایست'
python -m examples.nasuraya_research.articulated.motion_commands run --session /tmp/nasuraya-demo-new --id second --command 'یک قدم جلو برو و بایست'
```

مسیر نشست برای دستور `start` باید تازه باشد. سقف نشست قابل تنظیم، از یک تا شش قدم است؛ اجرای مستند حاضر فقط دو قدم را بررسی کرده است.

## شواهد و فیلم

`evidence/functional-motion-v01/` شامل رسیدهای دو فرمان، وضعیت پایانی، آرایهٔ حالت‌های ثبت‌شده، نتیجهٔ آزمون‌ها و `summary.json` است. بازپخش شناسهٔ فرمان اول پس از فرمان دوم نیز آزمایش شد؛ پروندهٔ نشست حتی در سطح بایت تغییر نکرد.

```bash
MUJOCO_GL=egl python -m examples.nasuraya_research.articulated.render_motion_commands --session evidence/functional-motion-v01 --output /tmp/Nasuraya_Command_and_Motion.mp4
```

فیلم از حالت‌های ثبت‌شدهٔ شبیه‌ساز ساخته می‌شود، با نمای کامل بدن و نمای نزدیک پاها. هیچ حرکت مولد تصویری یا تکرار مصنوعی یک چرخه به آن اضافه نشده است. مدت ۲۲ ثانیه، ۲۰ فریم در ثانیه و قالب H.264 با وضوح ۷۲۰×۱۰۸۰ است. دو ثانیهٔ آماده‌سازی آغازین در فیلم نیست.

## اعتبارسنجی و حدود نتیجه

۲۷ آزمون محلی موفق بودند: ۸ آزمون جدید بازیابی v03، ۱۴ آزمون موجود بازیابی/بدن/قدم‌زدن، و ۵ آزمون رابط فرمان. این‌ها نتیجهٔ محلی‌اند، نه ادعای موفقیت CI. علاوه بر آن، دو فرمان واقعی در فرایندهای جدا و بازپخش شناسهٔ قبلی بررسی شدند.

بازیابی v03 اختیاری و وابسته به نسخهٔ منبع، مدل کامپایل‌شده، وابستگی‌ها و هندسهٔ تکیه‌گاه است. قبل از تغییر بدن مقصد، سازگاری روی دادهٔ موقت بررسی می‌شود. قرارداد بازیابی v02 حفظ شده است.

این مرحله فقط پاسخ مکانیکی یک مدل فنی روی سطح صاف را نشان می‌دهد. توقف اضطراری میان حرکت، دیدن و گرفتن هدف، سازگاری با زمین ناهموار، مدل اندام‌های زیستی و تجربهٔ ذهنی از آن نتیجه نمی‌شوند. چهره و پوست هنری نیز جزئی از این فیلم نیستند. ادامهٔ توسعه باید با کار عملی بعدی و شواهد حرکت سنجیده شود.
