# آزمایش ۰۳: بدن ← انگیزش ← پیشنهاد تصمیم
تاریخ ۲۰۲۶-۱۱-۰۶

این تغییر یک رابط فقط‌خواندنی `drive_decision_bridge.py` اضافه می‌کند؛ از گزارش تولیدشده توسط `InstinctController` و مشاهدهٔ checkpoint واقعی **بدن نرم‌افزاری** برای پیشنهاد رفتار استفاده می‌شود. هیچ حرکت یا اقدام بیرونی مجاز نیست.

## اولویت‌های آزمون
- درخواست فاصله یا رد رضایت، حتی با میل قراردادی بالا، به `respect_boundary` منجر می‌شود.
- درد >= ۰٫۷، خستگی >= ۰٫۸ یا بار سمپاتیک قراردادی >= ۰٫۸ می‌تواند پیشنهاد عادی را به `regulate_and_rest` تبدیل کند.
- محبت خانوادگی در کانال مستقل و غیرجنسی باقی می‌ماند.
- هر گزارش با منشأ یا دامنهٔ ناشناخته رد می‌شود.
- بازکردن نشست ذخیره‌شده، نتیجهٔ پیشنهاد را برای رویداد بازپخش‌شده ثابت نگه می‌دارد.
- `actuation_authorized=False` و `native_cycles_caused=0` همواره برقرار هستند.

## اجرا

```bash
python3 -m unittest examples.nasuraya_body_loop.test_drive_decision_bridge_20261106 -v
```

## مرز نتیجه
این رابط هنوز به DecisionCore برای اجرای کنش متصل نیست و به آن اجازهٔ حرکت نیز نمی‌دهد؛ صرفاً یک لایهٔ تصمیم پیشنهادی با اولویت‌های غیرقابل‌دورزدن را بررسی می‌کند. فیزیولوژی حقیقی، رضایت حقیقی، میل حقیقی یا تجربهٔ ذهنی اندازه‌گیری نشده‌اند. خروجی تست GitHub Actions باید مستقل بررسی شود.
