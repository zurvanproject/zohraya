# اتصال تجربه، حالت عاطفی و خودپیش‌بینی — ۲۳ اکتبر ۲۰۲۶

در این تغییر، چهار ایدهٔ بررسی‌شده به کنترل‌گر اختیاریِ همان `BodyLoop` متصل
شده‌اند. کنترل‌گر ترجیح walk/observe را انتخاب می‌کند و `UnifiedBody.cycle()`
واقعاً آن را اجرا یا وتو می‌کند. اثر انتخاب در رسید ثبت می‌شود. حالت، پیش‌بینی
و تجربهٔ نتیجه در SQLite همان نشست حفظ می‌شوند. مدل زبانی، وزن‌های ChatGPT،
بدن فیزیکی، عامل API و زمان‌بند دائمی در این تغییر فعال یا اصلاح نشده‌اند.

کدها و مجوزهای هر چهار منبع خوانده شدند. مجوز Aura مشاهده/یادگیری را مجاز
می‌داند ولی استفاده و بازتوزیع کد را منع می‌کند؛ Anima/stell مجوز غیرتجاری
دارد. هیچ کد، کلاس، فایل یا متن بیانِ هویتی از این دو منتقل نشده است. اجرای
ایده‌های عمومیِ کنترل حالت و پیش‌بینی در این تغییر مستقل و مخصوص قرارداد
بدن زهرایا است. دو منبع دیگر MIT هستند؛ از آن‌ها نیز کد vendor نشده است.

در کد حافظهٔ Anima/huodebing، decay بر اساس کل فاصله از آخرین بازیابی دوباره
در strength ضرب می‌شود؛ فراخوانی مکرر می‌تواند همان بازه را چندبار بشمارد.
اینجا `last_decay_at` جداگانه داریم: دو مرور در یک زمان، زوال دوباره ایجاد
نمی‌کند. همچنین برخلاف بیان ضربیِ بعضی توضیحات آن پروژه، کد recall جمعِ
وزن‌دارِ مؤلفه‌ها را محاسبه می‌کند. این تفاوت در انتخاب طراحی لحاظ شده است.

## اتصال و دامنه

زهرایا پیش‌تر در `retained_extensions` مدل عاطفی و در هستهٔ بدن حفاظت و
پیش‌بینی داشت. فایل‌های بازیابی‌شده و اثرانگشت آن‌ها دست‌نخورده‌اند. این افزونه
روی سطح تصمیم میزبان کار می‌کند؛ valence/arousal آن خوانش مهندسیِ تجربهٔ
کنترل‌گر است و جایگزین حالت عاطفیِ موجودِ بدن یا یک احساس زیستی نیست.

پیش‌بینی برای چهار متغیرِ نرمال‌شدهٔ energy/fatigue/pain/sleep_pressure است؛
به زمینهٔ فیزیکی، ترجیح و مدت بسته می‌شود. تخمین اولیه «بدون تغییر» است و پس
از نتایج واقعی، میانگین تغییر به‌روز می‌شود. خطا احتمال کالیبره‌شده نیست و
کاهش عمومی خطای پیش‌بینی هنوز از این نمونه‌های کوتاه نتیجه نمی‌شود.

مرور، چرخهٔ خواب فیزیولوژیک نیست: خلاصهٔ تجربه و پیشنهادِ مقایسه می‌سازد.
فرضیه‌ها به‌عنوان مشاهده وارد تصمیم نمی‌شوند. هیچ خاطره یا تعهد قبلی حذف
نمی‌شود. ورودی از رسیدهای همین کنترل‌گر است، نه خاطرات آزادِ تولیدشده با مدل.

قفل، بودجهٔ پایدار و وتوی بومی حفظ می‌شوند. ثبت intent پیش از اجرای بدن است؛
اگر پس از commit بدن وقفه رخ دهد، همان رسید بازیابی می‌شود و اجرا تکرار
نمی‌شود. وضعیت running حل‌نشده همچنان به تطبیق نیاز دارد. replay تکمیل‌شده
نه بدن را دوباره اجرا می‌کند، نه تجربه را دوباره می‌آموزد. هش وضعیت تشخیص
تغییر تصادفی است، نه دفاع در برابر کسی که مستقیم پایگاه و هش را بازنویسی کند.

## استفاده

از ریشهٔ مخزن، با Python 3.11+ و Linux، بدون کلید و وابستگی جدید:

```sh
python3 -m examples.nasuraya_body_loop experience-test
python3 -m examples.nasuraya_body_loop experience-demo --output-dir /tmp/new-experience-demo

python3 -m examples.nasuraya_body_loop start --fixture sleep --max-actions 3 --session /tmp/new-experience.sqlite
python3 -m examples.nasuraya_body_loop experience-enable --session /tmp/new-experience.sqlite
python3 -m examples.nasuraya_body_loop experience-step --decision-id first --session /tmp/new-experience.sqlite
python3 -m examples.nasuraya_body_loop experience-consolidate --session /tmp/new-experience.sqlite
python3 -m examples.nasuraya_body_loop experience-status --session /tmp/new-experience.sqlite
```

`experience-step` خودش مشاهدهٔ تازه می‌گیرد. فرمان‌های قدیمی و API همچنان مسیر
قبلی را دارند؛ فعال‌سازی افزونه به‌معنای تغییر خودکار آن مسیرها نیست. شروع روی
فایل موجود ممنوع است؛ برای نشست موجود فقط enable یک‌باره و سپس resume کنید.
چهار پرچم از طریق `ExperienceController.enable(loop, memory=False, ...)` برای
آزمون حذف لایه در دسترس‌اند و با نشست حفظ می‌شوند.

دمو دو نشستِ fixture نرمال/فشارخواب، سه چرخه برای هرکدام، بازشدن مجدد نشست،
مرور و مقایسهٔ انتخاب با حذف لایه‌ها را ثبت می‌کند. این آزمایشِ ساخته‌شدهٔ
قراردادهاست؛ معیار عامِ هوش، خودآگاهی یا کیفیت گفت‌وگو نیست.

ReflectionCycle قبلی نیز پس از وتوی بدن می‌توانست اقدام نهایی را عوض کند.
بنابراین راه‌رفتن ← حفاظت ← مشاهده به‌تنهایی قابلیت تازه یا برتری بر نسخهٔ
قبلی نیست. بخش تازه، تغییرِ ترجیح پیش از آن هسته با تجربهٔ هم‌زمینه، ثبت
پیش‌بینی عددیِ قبل از اجرا، حالت عاطفیِ پایدار و مرورِ منبع‌دار است. مقایسهٔ
حذف حافظه در دمو فقط اثر آن بر ترجیح را نشان می‌دهد، نه افزایش موفقیت عمومی.
