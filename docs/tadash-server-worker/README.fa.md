# اجرای مستقل مدل ناسورایا روی سرور — نسخهٔ ۱

این نسخه واسطهٔ Work را از حلقهٔ ابزارها حذف می‌کند: وظیفهٔ دائمی ویندوز مستقیماً Agents API را فراخوانی می‌کند، ابزارهای محدود تداش را روی همان سرور اجرا می‌کند و رسیدهای محلی را برای ارزیابی به مدل برمی‌گرداند. پل فعلی GitHub فقط برای نصب، پذیرش یک هدف مشخص و گزارش وضعیت باقی می‌ماند.

## رفتار و دامنه

- مدل: `gpt-6-astra`؛ بدون محیط ابری، shell یا subagent.
- وظیفهٔ `NasurayaModelWorker`: حساب SYSTEM، سطح Highest، محرک AtStartup، راه‌اندازی مجدد پس از شکست و جلوگیری از اجرای هم‌زمان.
- صف خصوصی: `%PROGRAMDATA%\NasurayaModelWorker\inbox`.
- هر فایل هدف دقیقاً شامل `goal_id`، `text` و `max_cycles` است؛ چرخه‌ها ۱ تا ۳ هستند.
- صف خالی هیچ درخواست API یا هزینهٔ مدل ایجاد نمی‌کند؛ این نسخه هدف تازه‌ای به‌صورت خودکار تولید نمی‌کند.
- سقف پذیرش: دو هدف در روز UTC و پنج هدف در کل دفتر این نسخه. سقف ابزار: ۱۲ فراخوانی و ۸۰ درخواست API در هر هدف.
- مهلت اجرای هدف ۱۲۰ ثانیه است؛ درخواست شبکه و پاک‌سازی نشست نیز زمان محدود دارند. این محدودیت‌ها سقف دلاری تضمین‌شده از طرف سرویس نیستند.
- سقف قدیمی ۲۰ عمل در دفتر اصلی تداش حفظ می‌شود؛ داده‌ها و اهداف قبلی پاک نمی‌شوند.
- هر ابزار بومی در فرایند تازهٔ Python اجرا می‌شود تا مسیر موقت و پیش‌فرض‌های منبع اصلی در فرایند دائمی باقی نمانند.
- تداش حاضر شبیه‌سازی نرم‌افزاری قدیمی با جرم تجمیعی ۱۹۵ کیلوگرم است؛ این نصب جایگزین مدل مفصل‌دار ۷۸ کیلوگرمی یا محرک فیزیکی نیست.

## نگهداری کلید

کلید اختصاصی از فایل خصوصی قبلی انتخاب شد. سرور یک جفت RSA موقت ۴۰۹۶ بیتی ساخت؛ کلید خصوصی گیرنده با DPAPI حساب موجود محافظت شد. چهار قطعهٔ عمومی پس از تطبیق نویسنده و شناسهٔ درخواست گردآوری شدند. انتقال کلید با RSA-OAEP-SHA1 سازگار با CSP ویندوز قدیمی انجام شد؛ فقط ciphertext در کد ثابت انتقال قرار گرفت.

روی سرور، خروجی رمزگشایی فقط در حافظه به DPAPI LocalMachine تبدیل شد. فایل `api-key.dpapi` در مسیر با ACL محدود به SYSTEM و Administrators قرار دارد. فایل خصوصی RSA پس از موفقیت انتقال حذف شد. کلید روشن در GitHub، خط فرمان، محیط یا گزارش ذخیره نمی‌شود. مدیر محلی و SYSTEM جزو مرز اعتماد هستند؛ DPAPI LocalMachine به‌تنهایی جای ACL را نمی‌گیرد.

TLS با مجموعهٔ CA عمومی certifi 2026.10.19 و مجوز همراه بسته بررسی می‌شود؛ redirect و proxy محیطی در انتقال مستقیم API غیرفعال‌اند. مبدأ API ثابت است. خطاهای منتشرشده فقط کد پالایش‌شده دارند.

## نصب و بازیابی

بستهٔ مستقل به commit و SHA-256 ثابت مقید است. نصب‌کننده فایل‌ها و manifest را پیش از ثبت وظیفه بررسی می‌کند، دفتر تداش موجود را تأیید می‌کند و پیش از پذیرش هدف، ضربان تازهٔ SYSTEM همراه با دسترسی به کلید محافظت‌شده را انتظار می‌کشد. اگر شروع موفق نشود، فقط وظیفه‌ای که همین نصب ایجاد کرده حذف می‌شود. وظیفه یا پیکربندی ناشناس بازنویسی نمی‌شود.

برای توقف مدل، مدیر سرور یک فایل خالی به نام `STOP` در پوشهٔ خصوصی خدمت می‌گذارد. خدمت در حالت paused می‌ماند؛ برداشتن آن پذیرش صف را از سر می‌گیرد. برای توقف خود فرایند، `Stop-ScheduledTask -TaskName NasurayaModelWorker` اجرا می‌شود؛ غیرفعال‌کردن وظیفه، شروع بعدی در بوت را هم متوقف می‌کند. این اقدامات پل قدیمی را تغییر نمی‌دهند.

دفتر خصوصی `state/worker.sqlite` هدف، شناسهٔ نشست، outbox ابزارها، رسیدها و گزارش نهایی مدل را نگه می‌دارد. نتیجهٔ یک ابزار با شناسهٔ یکسان دوباره در بدن اجرا نمی‌شود. نتیجهٔ نامطمئن یا اثر بومی حل‌نشده مسدود می‌شود؛ اجرای قبلی حدس زده نمی‌شود.
