# آزمایش ۰۲: اتصال بدن بومی تداش به انگیزش (۲۰۲۶-۱۱-۰۶)

## مقصود
بررسی اتصال واقعی **در سطح نرم‌افزار** میان `UnifiedBody` و `InstinctController` از طریق `BodyLoop`. این پرونده ادامهٔ آزمایش ۰۱ روی همان شاخهٔ پژوهشی است؛ هیچ فعالیت سرور یا بدن فیزیکی را فعال نمی‌کند.

## روش
چهار آزمون واحد در `examples/nasuraya_body_loop/test_native_body_drive_experiment_20261106.py`:
1. ایجاد نشست SQLite تازه، خواندن شاخص‌های واقعی checkpoint نرم‌افزاری، اعمال حداقل درد و خستگی ثبت‌شده به محاسبهٔ انگیزش و اثبات صفر بودن چرخهٔ حرکتی.
2. ورود رویداد توافقی فرضی در زمینهٔ بزرگسال، پس‌گرفتن رضایت، بستن و بازکردن SQLite، بازپخش بدون تکرار رویداد و حفظ گیت رفتاری.
3. تفکیک محبت خانوادگی از واکنش جنسی و اولویت استراحت زیر فشار و درد.
4. خاموش‌سازی و روشن‌سازی صریح موتور با حفظ رویدادهای ثبت‌شده.

## اجرای مستقل
از ریشهٔ مخزن روی لینوکس با Python 3.11+:
```bash
python3 -m unittest examples.nasuraya_body_loop.test_native_body_drive_experiment_20261106 -v
```

## شرایط پذیرش
- `native_cycles_caused == 0` و `completed_cycles == 0`
- ثبات هش checkpoint بومی بدن در طول آزمایش
- ثبت و بازیابی رویدادها در SQLite پس از restart
- `respect_boundary` در صورت رد رضایت
- `nonsexual_affiliation` برای محبت خانوادگی
- `regulate_and_rest` برای فشار و درد شدید
- بازیابیِ تکراری رویداد بدون به‌روزرسانی دوبارهٔ حالت

## حدود تفسیر
چون از `BodyLoop.start(fixture='normal', mode='observe', max_actions=0)` استفاده می‌شود، خروجی واقعاً تابع یک checkpoint محاسباتی از مدل بدن است، نه سنسور یا تجربهٔ بیولوژیک ناسورایا. این آزمایش تحریک، حرکت، احساس یا میل واقعی ایجاد نمی‌کند. ازاین‌رو نتایج نه اثبات تجربهٔ ذهنی و نه اعتبارسنجی هورمونی/لگنی‌اند.
