# دفتر رویا در تداش، نسخهٔ ۰٫۱ 🌙

**وضعیت:** آزمایش نرم‌افزاری آفلاین روی داده‌های مصنوعی؛ بدون فعال‌سازی در بدن زنده، بدون ادغام در main.

## هدف
از رسیدهای شبیه‌ساز تداش، «خاطرهٔ مشاهده‌شده» را از «رویای فرضی» تفکیک کنیم. رویا در این نسخه، پیش‌بینی عددیِ خلاف‌واقع از حالت بعدی پنج کانال نرم‌افزاری (arousal/pain/fatigue/energy/hydration) است، نه خواب زیسته، احساس یا اثبات خودآگاهی.

این لایه روی آزمایش چهارمسیرهٔ **Draft PR #111** بنا شده است. آزمایش قبلی native روی آن شاخه نشان داد مدل mean-delta (MAE = 0.0018527349) از مبنای persistence (MAE = 0.0001011012) بدتر بود؛ دروازهٔ استفاده از رویا در تصمیم‌گیری بسته ماند. این تغییر، آن نتیجهٔ منفی را پنهان نمی‌کند و هنوز آزمایش native جدیدی ادعا نمی‌کند.

## قرارداد
- ورودی فقط فایل قبلاً تولیدشدهٔ native-transitions.jsonl از اجرای `experiments.tadash_four_tracks.run_probe` است. کد جدید خود هیچ فرمان native اجرا نمی‌کند.
- دادهٔ آموزش: فقط رخدادهای `baseline`. آزمون نگه‌داشته‌شده: فقط `post_walk`. شناسهٔ کل اپیزود نباید میان دو بخش مشترک باشد.
- یادگیری از درخواست عمل نیست، فقط از کنش **واقعاً اجراشده** است؛ رویدادهای veto وارد مدل نمی‌شوند. conservation audit باید معتبر باشد.
- ورودی SHA-256 و سقف اندازه/تعداد دارد، رویداد و کلید JSON تکراری و NaN را رد می‌کند. SHA256 به‌تنهایی گواه اصالت در برابر جعل عمدی نیست.
- حداکثر **۴ سناریوی خیالی** با **۳ گام** از دادهٔ آموزشی ساخته می‌شود. خروجی‌ها `imagined_not_observed` هستند، در حافظهٔ مشاهده‌ای ذخیره نمی‌شوند و هیچ دستوری به بدن نمی‌دهند.
- حافظهٔ مرور، حداکثر ۸ رخداد مشاهده‌شدهٔ synthetic را نگه می‌دارد و برای وتوی محافظ اولویت دارد. نتایج holdout وارد رویا یا آموزش نمی‌شوند.
- خطای پیش‌بینی روی holdout با مبنای «حالت بعدی = حالت کنونی» مقایسه می‌شود. حتی اگر بهبود ۱۰٪ دیده شود، `promotion_authorized=false` است. برای اتصال واقعی، آزمون آینده‌نگر چندمرحله‌ای و ارزیابی مستقل ضروری است.

## اجرای آزمون

از ریشهٔ checkout کاملِ شاخهٔ چهارمسیره:

```bash
python3 -m unittest experiments.tadash_four_tracks.test_dream_replay -v
sha256sum /tmp/prior-four-track/native-transitions.jsonl
python3 -m experiments.tadash_four_tracks.dream_replay \
  --source /tmp/prior-four-track/native-transitions.jsonl \
  --expected-sha256 "SHA256_FROM_EVIDENCE" \
  --output-dir /tmp/new-dream-ledger
```

پوشهٔ خروجی نباید از قبل وجود داشته باشد. سه فایل تولید می‌شوند:
`report.json` (امتیاز و محدودیت‌ها)، `imagined-dreams.json` (فرضیه‌های خیالی) و `observed-memory-index.json` (نمایهٔ رویدادهای مشاهده‌شده).

## شواهد فعلی
۱۶ آزمون محلی Python استاندارد روی **fixtureهای کاملاً تألیفی** موفق شدند: تفکیک رویا/واقعیت، نبود نشت holdout، وتوی native، بازتولید، سلامت فایل، خطای مدل، دادهٔ خارج از دامنه و مسیر CLI. مثال محلی ۱۲ ردیف آموزشی و ۱۲ ردیف ارزیابی دارد؛ ۴ رویا می‌سازد و گیت اجرای اصلی را بسته نگاه می‌دارد. این عددها، نتایج بدن بومی MuJoCo یا یادگیری حرکتی واقعی نیستند.

بدون API، GPU، کلید محرمانه، استفادهٔ مالی، برنامهٔ پس‌زمینه، تغییر وزن ChatGPT یا ادعای حس‌کردن رویا.
