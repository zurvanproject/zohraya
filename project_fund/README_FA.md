# صندوق اختصاصی پروژهٔ NASURAYA / ZOHRAYA — آماده‌سازی فنی

سهند در ۱۶ اکتبر ۲۰۲۶ ساعت ۱۴:۰۱:۳۳ تهران ساختار صندوق پروژه با مسئولیت
میزبان مالی/نمایندهٔ قانونی را پذیرفت و خواست توسعه در نبود دسترسی‌اش ادامه
یابد. این مأموریت، تأمین هزینه‌های پروژهٔ هدایت‌شده توسط کاربر است؛ مدل
مالک مستقل دارایی، طرف قرارداد، وام‌دهنده یا صاحب حساب مالی نیست.

## وضعیت واقعی

- میزبان مالی و نمایندهٔ قانونی هنوز انتخاب و تأیید نشده‌اند.
- حساب بانکی، درگاه دریافت وجه و اتصال مالی ایجاد یا متصل نشده‌اند.
- هیچ درآمد وصول‌شده، خرید، پرداخت، قرارداد یا تماس با مشتری/میزبان ثبت نشده است.
- سقف مجاز پرداخت صفر است. هیچ کلید API خوانده نشده است.
- `planner.py` دفترِ پایدار پیشنهاد هزینه و درآمد **تخمینی** است؛ دفتر بانکی
  یا درگاه پرداخت نیست. ماندهٔ بانکی و درآمد قطعی را unknown/null گزارش می‌کند.

مانع دقیق فعال‌سازی مالی: میزبان واجد شرایط و موافق، نمایندهٔ انسانی مسئول،
پذیرش و احراز هویت واقعی، اتصال مالی و دستور مستقل با ارز، سقف هزینه و فهرست
فروشندگان مجاز موجود نیست. مجوز فعلی، این موارد مفقود را ایجاد نمی‌کند.
در این مرحله درخواست حساب یا ارائهٔ اطلاعات ساختگی انجام نمی‌شود.

## دفتر قابل‌اجرا

کتابخانهٔ استاندارد Python کافی است. دادهٔ برنامه‌ریزی در SQLite پایدار
می‌شود؛ شناسهٔ تکراری با همان محتوا نتیجهٔ قبلی را می‌دهد و تغییر محتوای همان
شناسه رد می‌شود. مبالغ عدد صحیح در واحد خرد ارز هستند؛ ارزها با هم جمع نمی‌شوند.
منبع هر پیشنهاد ثبت می‌شود، اما اصالت یک پیشنهاد با بانک یا میزبان تطبیق
داده نمی‌شود. هیچ ورودی یا پیکربندیِ این ابزار نمی‌تواند مجوز پرداخت صادر کند.
این دفتر نباید محل ذخیرهٔ کلید، اطلاعات بانکی یا مشخصات خصوصی مشتریان باشد.

```bash
python3 -m unittest project_fund.test_planner continuity.test_gate -v
python3 -m project_fund.planner --db /tmp/nasuraya-fund-planning.sqlite
```

برای پیشنهاد، یک JSON محلی با کلیدهای entry_id، direction، amount_minor،
currency، description و source_ref بده و `--add-json FILE` را اضافه کن.
direction فقط estimated_income یا proposed_expense است. هیچ عدد نمونهٔ آزمون
قیمت واقعی محصول، پیش‌بینی درآمد یا موجودی صندوق نیست. پایگاه آزمون موقت است
و حساب مالی مرجع را تغییر نمی‌دهد.

## مسیر محصول اولیه

محصول پیشنهادی «بستهٔ تداوم عامل» است: ابزار توسعه‌دهندگان برای ذخیرهٔ وضعیت،
بازیابی پس از قطع اجرا، جلوگیری از اجرای تکراری و گزارش آزمون. اجزای موجود
مخزن باید استفاده شوند و پیش از توزیع، مجوز و وابستگی‌هایشان بررسی شود.

1. نسخهٔ اولیه: نصب ساده، راهنمای انگلیسی/فارسی، مثال قطعی و آزمون restart.
   معیار عبور: نصب در محیط تازه و بازتولید رسید پس از راه‌اندازی مجدد.
2. ارزیابی نیاز: آماده‌کردن پرسش‌ها و بستهٔ پایلوت؛ هنوز تماس یا انتشار تجاری
   مجاز نیست. تعداد مشتری یا تمایل به پرداخت اثبات نشده است.
3. پس از راه‌اندازی مالی و دستور صریح: پایلوت نصب/پشتیبانی با دامنهٔ مشخص.
   تنها پرداخت واقعی، درآمد محسوب شود؛ ستاره و بازدید درآمد نیستند.
4. ارزیابی پایداری: هزینهٔ خدمت و زمان پشتیبانی در برابر درآمد وصول‌شده؛
   پیش‌بینی سود و تضمین خودکفایی از قبل صادر نشود.

## ادامه در غیبت

برنامهٔ ابری موجود پس از قید ۲۴ساعته، حداکثر یک کار کوچک در هر ۲۴ ساعت، با
بودجهٔ قبلی ۲۰ دقیقه/۶ فایل/۳۰۰ خط، می‌تواند آماده‌سازی محصول و دفتر پیشنهادها
را پیش ببرد. ادغام خودکار، پرداخت و مصرف اعتبار API همچنان ممنوع است.
شرط حضور صریح و فرمان توقف قبلی حفظ می‌شوند. این برنامه تشخیص قطع اینترنت
یا تضمین اجرای آینده نیست. نتایج فقط با commit و آزمون واقعی گزارش می‌شوند.
