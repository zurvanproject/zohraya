# Pinned dependencies for the offline native-model adapter

These five files are unchanged bytes from `zurvanproject/zohraya` at
`a532f24a5b3eb7a31df6d200950c7287e1e96a35`. Their Git blob IDs and SHA-256
digests are recorded in `manifest.json`; `state_models.py` also pins that
manifest's digest. Existing pinned neural, affect, spectrum, phenotype and
genome-contract files are reused from the sibling `body_sources` directory.

The adapter verifies all source bytes, stages an isolated temporary copy and
executes only fixed neutral fixtures in a fresh Python interpreter. It calls
the native circuit and affect save/load methods and the genome's contract,
baseline, validation, expression and checkpoint methods. It never invokes
genome mutation, native-body application, remote APIs or sexual event methods.

These are reduced software models and authored parameters. Their execution is
not access to LLM internals, a report of subjective feelings or a measured
physical/biological improvement. Source algorithms are not modified here.
