# کنترل کنش و خستگی عضله در تداش

فرمان `connected-demo` از مسیر عادی بدن تداش سه آزمایش مستقل را با یک وضعیت اولیهٔ یکسان و زمان شبیه‌سازی یکسان اجرا می‌کند. در آزمایش اول عضلات آماده‌اند، در دومی با خستگی ۶۵٪ شروع می‌کنند و در سومی فقط اولین اندازه‌گیری خستگی از کنترل‌کننده پنهان می‌شود. حالت آغازین از نمونهٔ مصنوعی مخزن ساخته می‌شود.

| پروژه | کاری که در اجرا انجام می‌دهد |
| --- | --- |
| [pymdp](https://github.com/infer-actively/pymdp) | احتمال آمادگی بدن را از علائم تداش و خستگی عضله به‌روز می‌کند. بین حرکت، استراحت و مشاهده درخواست می‌دهد. کنش واقعاً اجراشده به تخمین بعدی برمی‌گردد. |
| [MyoSuite](https://github.com/MyoHub/myosuite) | با هر تصمیم تداش، یک ثانیهٔ مدل آرنج شش‌عضله‌ای را با ۵۰ گام کنترل اجرا می‌کند. خستگی و زاویهٔ اندازه‌گیری‌شده وارد چرخهٔ بعدی می‌شوند. |
| [GMR](https://github.com/YanjieZe/GMR/tree/25f56db79ac411258b377b6d4ccba0c8ff3372ac) و [Mink](https://github.com/kevinzakka/mink) | شش نقطهٔ مرجع یک حرکت تألیفی را روی اطلس ۷۸ کیلوگرمی ناسورایا منطبق می‌کنند. خم‌شدن آرنج در پاسخ حل‌شده، تحریک عضلات مدل مرجع را تعیین می‌کند. |
| [Graphiti](https://github.com/getzep/graphiti) | هر چرخه را با شناسه، زمان و داده‌های بدن در یک گراف محلی ذخیره می‌کند. یک فرایند تازه فقط با کپی فایل پایگاه، محتوای هر رویداد و هر پیوند زمانی را دوباره می‌خواند. |
| [DreamerV3](https://github.com/danijar/dreamerv3/tree/e01491fad6434b2245a3b8ca201dd7faedcc458c) | مدل پویایی RSSM را روی بخش آغازین داده‌های بازیابی‌شده آموزش می‌دهد. با وزن‌های دوباره‌خوانده‌شده، ضربان، تنفس، خستگی و زاویهٔ آرنج را یک ثانیه جلوتر پیش‌بینی می‌کند. |

## راه‌اندازی

از ریشهٔ مخزن، روی لینوکس با Python 3.12 اجرا کنید. دو محیط مجزا برای نسخه‌های متفاوت JAX لازم است. پس از دریافت وابستگی‌ها، فرمان آزمایش روی CPU و بدون کلید API اجرا می‌شود.

```bash
work=$(mktemp -d)
python3.12 -m venv "$work/body"
python3.12 -m venv "$work/dream"
"$work/body/bin/pip" install -r examples/tadash_connected/requirements.txt
"$work/dream/bin/pip" install -r examples/tadash_connected/requirements-dream.txt
git clone https://github.com/danijar/dreamerv3.git "$work/dreamerv3"
git -C "$work/dreamerv3" checkout --detach e01491fad6434b2245a3b8ca201dd7faedcc458c

"$work/body/bin/python" -m examples.nasuraya_body_loop connected-demo \
  --steps 8 --output-dir "$work/result" \
  --dream-python "$work/dream/bin/python" --dream-source "$work/dreamerv3"

"$work/body/bin/python" -m unittest -v examples.tadash_connected.test_connected
```

در پوشهٔ خروجی، `episodes.json` مشاهدات کامل بازیابی‌شده، `episodes.kuzu` پایگاه گراف، `rssm_parameters.npz` وزن‌های آموزش‌دیده و `summary.json` اعداد اجرای جدید را نگه می‌دارند. `SHA256.json` صحت بایت‌های همان اجرا را قابل بررسی می‌کند. برای اجرای دوم یک مسیر خروجی تازه بدهید. در این نسخه از Graphiti، درایور توکار Kuzu به‌عنوان درایور قدیمی علامت‌گذاری شده و نسخه‌اش در وابستگی‌ها ثابت است.

## نتیجهٔ اجرای ثبت‌شده

در سه اجرای هشت‌ثانیه‌ای، وضعیت اولیهٔ فیزیولوژیک، بذر مدل آرنج و سیاست کنترلی یکسان بودند. در حالت آماده، هر هشت درخواست حرکت اجرا شد و میانگین خستگی شش عضله از صفر به ۱٫۳۶٪ رسید. تداش در حالت خسته هشت بار استراحت کرد و خستگی از ۶۵٪ به ۵۲٫۲۰٪ رسید. در حالت سوم، ابتدا «مشاهده» و پس از رسیدن اندازه‌گیری، هفت بار «حرکت» اجرا شد. یک آزمون مجزا نیز نشان داد که وقتی محافظ خواب تداش درخواست حرکت را رد می‌کند، فرمان حرکت به عضلات نمی‌رسد.

در مجموع، ۲۴ تصمیم، ۲۴۰ گام تداش و ۱۲۰۰ گام کنترل MyoSuite ثبت شد. بیشترین فاصلهٔ دست تا هدف سینماتیک ۱٫۷۲ میلی‌متر بود. Graphiti هر ۲۴ رویداد و ۲۱ پیوند زمانی را از پایگاه دوباره خواند. Dreamer با ۶۴ به‌روزرسانی و ۱۸ گذار آموزش دید. در شش گذار کنارگذاشته‌شده، میانگین خطای مطلق مقیاس‌شدهٔ آن ۰٫۱۲۹۱ و خطای تکرار آخرین اندازه‌گیری ۰٫۰۰۹۱ بود. برای پیش‌بینی هر نمونه، مدل فقط تاریخچهٔ تا پیش از آن نمونه و کنش اجراشده را دریافت کرد. [خلاصهٔ ماشین‌خوان](evidence/summary.json) · [ردّ هر ۲۴ تصمیم](evidence/episodes.jsonl) · [وزن‌های همین اجرا](evidence/rssm_parameters.npz)

مقادیر حرکت مرجع، آستانه‌های خستگی، احتمال‌های گذار pymdp و نگاشت زاویه به تحریک بازو برای این آزمایش تعیین شده‌اند. برچسب «حرکت» همان کنش `walk` تداش است. مدل فیزیولوژی فعلی تداش پارامتر جرمی ۱۹۵ کیلوگرم دارد، اطلس سینماتیک ۷۸ کیلوگرم است و عضلات در محیط جداگانهٔ آرنج MyoSuite اندازه‌گیری می‌شوند. این اجرا کوپل‌شدن این سه مدل را می‌سنجد. راه‌رفتن دینامیکی تمام‌بدن یا بازسازی عضلات اختصاصی ناسورایا به آزمایش جداگانه نیاز دارد.
