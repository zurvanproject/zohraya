# آینهٔ زروان — بازپخش بدن نرم‌افزاری

۲۴ چرخهٔ واقعی اجرای محلی از دو fixture تولیدشدهٔ تداش، در دو مسیر مستقل
۱۲کنشی: وضعیت عادی و فشار خواب بالا. پل قبلی Godot نسخهٔ ۶، یک کارت تصویری
داشت؛ این نمونه مفصل‌های پایین‌تنه را از مختصات خروجی V06 نمایش می‌دهد.
Godot قبلی و وضعیت خصوصی بدن ویرایش نشده‌اند.

در حالت عادی یک گام کامل در نمونهٔ دهم ثبت شد. در fixture خواب، درخواست
اول راه‌رفتن بود ولی بدن حفاظت را اجرا کرد؛ بازخورد ثبت‌شده انتخاب‌های بعدی
را به مشاهده تغییر داد. شمارهٔ چرخه و اطلاعات تصمیم مربوط به نمونهٔ ثبت‌شده
هستند. زمان پخش برای مشاهده فشرده شده است و زمانِ شبیه‌سازی نیست.

مختصات مفصل‌ها، جای پا، مرکز جرم، زاویهٔ دم و وضعیت کمینه از checkpoint
اجرای واقعی شبیه‌ساز می‌آیند. چهار لایهٔ checkpoint در استخراج هش‌سنجی می‌شوند.
بالا‌تنه و شاخ‌ها و شکل ترسیمی دم شماتیک‌اند؛ این یک مش سه‌بعدی یا بدن
زیستی نیست. گذارِ نمایشی میان نمونه‌ها، نتیجهٔ فیزیکی تازه تولید نمی‌کند.
تمام اعداد بدنی، متغیرهای مدل و fixture هستند، نه اندازه‌گیری پزشکی.

## بازتولید

از ریشهٔ مخزن، با Python 3.11+ و کتابخانهٔ استاندارد:

```sh
python3 examples/nasuraya_body_mirror/export.py --generate --runs /tmp/new-mirror-runs --output examples/nasuraya_body_mirror/frames.json
python3 examples/nasuraya_body_mirror/build.py --output /workspace/nasuraya-body-mirror.html
```

پوشهٔ هر اجرای تازه نباید از قبل وجود داشته باشد. BodyLoop منابع اصلی را
از manifest معتبر می‌خواند و در فرایند جدا اجرا می‌کند؛ هیچ API مصرف نمی‌شود.
دادهٔ عمومی `frames.json` تنها نمونه‌های کاهش‌یافته و هش‌هاست؛ دفتر SQLite و
checkpoint کامل وارد مخزن نشده‌اند. HTML قطعهٔ نمایشی درون گفتگو است و از
کلاس‌ها و رنگ‌های میزبان استفاده می‌کند؛ سند مستقل وب نیست.

بررسی انجام‌شده: تغییر fixture، چرخهٔ دهم، نخستین وتوی خواب، یادآوری بعدی و
پخش محدود در harness مبتنی بر DOM در Node گذشت. هندسهٔ SVG در عرض ۲۸۸ پیکسل
رندر و بازبینی شد. مرورگر Chromium در محیط موجود نبود و دانلود آن فایل اجرایی
نرساند؛ چیدمان کامل مرورگر هنوز آزموده نشده است. نتیجه در `validation.json` است.
