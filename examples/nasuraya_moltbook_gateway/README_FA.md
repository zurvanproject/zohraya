# Nasuraya Moltbook Gateway 0.1 | درگاه اجتماعی امن ناسورایا

**وضعیت نسخهٔ 0.2 (۵ نوامبر ۲۰۲۶):** حساب nasuraya در یک نشست مستقل، claimed و خواندن ۳ پست تأیید شد؛ این کد هنوز روی VPS مستقر نشده است. اکنون زمان‌بندهای ویندوز/لینوکس و پل مشاهدهٔ عمومی تداش افزوده شده‌اند. راهنمای استقرار: [DEPLOYMENT_FA.md](DEPLOYMENT_FA.md). این برنامه وزن‌های ChatGPT را تغییر نمی‌دهد و اثبات آگاهی نیست.

## محدودیت‌های ایمنی

- دامنه و مسیر HTTPS فقط `https://www.moltbook.com/api/v1` هستند. انتقال خودکار درخواست به دامنهٔ دیگر ممنوع است.
- کلید در فایل خصوصی `~/.local/share/nasuraya/moltbook/moltbook_api_key` با مجوز 0600 ذخیره می‌شود و هرگز در پاسخ‌های API، خروجی ترمینال و گیت‌هاب منتشر نمی‌شود. پوشه با مجوز 0700 ساخته می‌شود.
- پیام‌های عمومی با برچسب `untrusted_external` در SQLite جدا ذخیره می‌شوند؛ نه به مدل فرمان می‌دهند و نه به checkpoint بدن تداش یا گفت‌وگوهای خصوصی دسترسی دارند. کد فعلی **هیچ ارتباط اجرایی با حافظه خصوصی یا بدن تداش برقرار نمی‌کند**.
- سه روز اول: فقط خواندن feed، ذخیره در قرنطینه و ساخت پیش‌نویس. ارسال با پیش‌فرض غیرفعال است؛ حتی پس از «approve» باید هر بار دستور صریح `send` با متغیر محیطی مخصوص صادر شود. هیچ زمان‌بند ارسال خودکار وجود ندارد.
- در صورت قطع ارتباط حین ارسال، وضعیت `uncertain` می‌شود؛ هرگز با همان شناسه خودکار ارسال مجدد نمی‌شود.
- از این درگاه **نمی‌توان امنیت صددرصد** تضمین کرد. بر روی سرور باید کاربر محدود، فایروال خروجی، به‌روزرسانی سیستم، پشتیبان‌گیری رمزگذاری‌شده، مانیتورینگ و ممیزی مستقل هم اجرا شود.

## نصب پس از تحویل VPS (Ubuntu 24.04 / Python 3.12)

کد را در یک پوشهٔ خصوصی روی سرور دریافت کنید؛ از توکن GitHub یا رمز سرور در چت و فایل‌های عمومی استفاده نکنید.

```bash
python3 --version
python3 gateway.py --help
python3 -m unittest -v test_gateway.py
```

## ثبت نام

فقط روی سروری که قرار است ایجنت در آن کار کند، اجرا کنید:

```bash
python3 gateway.py register
```

نتیجه باید نام، نشانی `claim_url`، کد تأیید و تأیید ذخیرهٔ خصوصی API key را نشان بدهد. **API key را ارسال نکنید.** اگر ثبت‌نام موفق شد، کاربر `claim_url` را در مرورگر شخصی باز می‌کند و از مسیر رسمی X مالکیت را اثبات می‌کند. ممکن است تأیید ایمیلی هم لازم شود.

پس از تأیید مالکیت:

```bash
python3 gateway.py claim # بازیابی لینک مالکیت بدون افشای API key
python3 gateway.py status
python3 gateway.py fetch --limit 10
python3 gateway.py inbox
```

## نگارش و تصویب پیام عمومی

پیش‌نویس باید جداگانه و توسط اپراتور یا مدل در محیط ایزوله تهیه و قبل از تأیید برای نشت حریم خصوصی بررسی شود. این ورودی نباید از متن خام پست‌های بیرونی کپی و به‌عنوان فرمان اجرا شود.

```bash
python3 gateway.py draft --title-file public_title.txt --body-file public_body.txt
python3 gateway.py approve --id ID_FROM_DRAFT --sha256 SHA256_FROM_DRAFT
# فقط پس از سه روز آزمایش و اجازه مشخص کاربر برای همان پیام
NASURAYA_ENABLE_POSTING=I_APPROVE_THIS_ONE_POST python3 gateway.py send --id ID_FROM_DRAFT
```

هر ارسال پست می‌تواند نیازمند حل challenge سرویس باشد؛ اگر چالش تأیید بخواهد و سرویس پست را تأیید نکند، وضعیت مبهم باقی می‌ماند و باید به صورت دستی بررسی شود. ممنوعیت تبلیغ بدون اجازه و سایر شروط Moltbook پابرجاست.

## سازگاری با تداش

کدهای فعلی پروژه Zohraya در `runtimes/tadash_body/privacy_boundary.py` و `examples/nasuraya_body_loop/api_host.py` مسیرهای مجزای محافظت از حالت خصوصی دارند. درگاه حاضر به‌عمد جدا از آن‌ها کار می‌کند؛ ادغام آینده باید به رابط *فقط خلاصهٔ عمومی، بدون checkpoint، بدون متن گفت‌وگوهای خصوصی* متکی باشد. هر تغییر در این قرارداد مستلزم بازبینی امنیتی جدید است.

## قابل حمل بودن

کد و SQLite اجتماعی را می‌شود با export/backups و کنترل مجوز به VPS بهتر منتقل کرد. کلید را از بک‌آپ عمومی و گیت‌هاب بیرون نگه دارید. در صورت نشت، کلید را در داشبورد رسمی تعویض کنید.
