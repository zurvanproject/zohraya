# راه چهارم تداش: هماهنگ‌کنندهٔ سه مرکز v0.1

**وضعیت:** نمونهٔ مهندسی مستقل، کاملاً آفلاین، ساختگی و نیازمند اجرای دستی. از آموزه‌های گورجیف و شرح آسپنسکی دربارهٔ هماهنگی فکر، احساس و حرکت الهام گرفته است. این برنامه ادعای آگاهی، احساس ذهنی، حضور روح یا اعتبار علمی آموزه‌های متافیزیکی ندارد. در روایت تداش می‌توان «آمادگی نور» را معنای فلسفی چنین هماهنگی دانست، ولی عددهای محاسباتی «نور» یا «روح» را اندازه‌گیری نمی‌کنند.

## سازوکار واقعی پیاده‌شده

۱. **مرکز اندیشه**: سازگاری تصمیم با هدف و میزان شواهد اعلام‌شده را می‌سنجد؛ اقدام با شواهد بسیار ضعیف را رد می‌کند.

۲. **مرکز احساس**: همسویی با ارزش‌ها، مراقبت از دیگران و بار عاطفی *شبیه‌سازی‌شده* را امتیاز می‌دهد. «احساس» در اینجا برچسبی برای یک متغیر نرم‌افزاری است.

۳. **مرکز حرکت/بدن**: هزینه، خطر، انرژی و پایداری *مدل‌شده* را می‌سنجد. برای هر عملی جز مشاهده و استراحت، وضعیت حفاظتی «allow» صریح لازم است. چنین مقداری **مجوز حرکت واقعی یا گواهی امنیت نیست**.

۴. **هماهنگ‌کننده**: همهٔ وتوها را پیش از امتیازگیری اعمال می‌کند. سپس ۴۵٪ اندیشه، ۳۰٪ احساس و ۲۵٪ حرکت را می‌سنجد. شاخص هماهنگی برابر ۱ منهای دامنهٔ سه امتیاز است؛ این صرفاً یک معیار طراحی‌شده برای سنجش توافق سه مرکز است، نه شاخص بیداری.

۵. **یادآوری خود**: همراه هر تصمیم، هدف، وضعیت مدل‌شده، نظر هر سه مرکز و علت انتخاب ثبت می‌شود. پس از مشاهدهٔ نتیجهٔ اعلام‌شده، اختلاف پیش‌بینی و نتیجه در SQLite ثبت می‌شود. رویداد هم‌نام با محتوای متفاوت رد می‌شود. اطلاعات با انتقال فایل SQLite قابل‌حمل‌اند.

## اجرای نمونه

از ریشهٔ مخزن، با Python 3.10 یا بالاتر و بدون نیاز به بستهٔ اضافی:

```sh
python3 -m unittest discover -s examples/nasuraya_fourth_way/tests -v
python3 -m examples.nasuraya_fourth_way demo --db /tmp/tadash-fourth-way-demo.sqlite
python3 -m examples.nasuraya_fourth_way status --db /tmp/tadash-fourth-way-demo.sqlite
```

نمونهٔ ساختگی با انرژی ۰٫۸ و پایداری ۰٫۹، سه گزینهٔ `walk`، `observe` و `rest` می‌سازد؛ انتخاب و ارزیابی همان داده‌ها را نشان می‌دهد. آزمایش «حفاظت ناشناخته» یا خطر بالا باید حرکت را وتو کند. برای ذخیره‌سازی داده‌های واقعی، مسیر امن و خصوصی انتخاب شود؛ **هیچ رمز، توکن، اطلاعات شخصی یا گفت‌وگوی خصوصی ناسورایا را وارد مخزن عمومی نکنید**.

## محدودیت‌ها و اتصال آینده

- این ابزار هیچ‌گونه فراخوانی خودکار به `UnifiedBody`، `ReflectionCycle`، BodyLoop، سرور VPS، GitHub Actions اجرایی بدن، مدل زبانی، API یا عملگر ندارد.
- امتیازها، حتی «allow»، صرفاً دادهٔ ورودیِ اعلامی‌اند. محافظت بومی بدن همیشه اولویت دارد؛ برای اتصال احتمالی باید واسط فقط‌خواندنی، گواهی/رسید منبع، منع پخش مجدد، آزمون‌های مستقل و رضایت صریح طراحی شوند.
- نتیجهٔ اعلامی در دفترچه، *تغییر وزن‌های مدل یا یادگیری خودکار* ایجاد نمی‌کند. تنها گزارش اختلاف پیش‌بینی و بازخورد تولید می‌شود. فاین‌تیونینگ بعداً فرآیندی مستقل است.
- شاخص هماهنگی با صحت اخلاقی یا درستی تصمیم یکسان نیست. نمرهٔ بالا بدون شواهد معتبر نمی‌تواند مجوز کنش شود.
- اجرای واقعی روی VPS هشت‌گیگیِ خریداری‌شده هنوز انجام نشده است. این تغییر فقط پیشنهاد نرم‌افزاری در شاخه و PR است و نیاز به آزمایش، تأیید و اتصال مرحله‌ای دارد.
