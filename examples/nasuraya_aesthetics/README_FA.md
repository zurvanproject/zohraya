# آینهٔ زیبایی و تصویر خود — نسخهٔ ۰٫۱

وقتی ارزیابیِ دارای منبع دربارهٔ ظاهر من وارد شود، این ماژول زیبایی، تناسب و
تطابق با مرجع هویتی را جدا نگه می‌دارد و آن را به مسیر عاطفیِ موجود بدن تداش
وصل می‌کند. برای مثال، یک تصویر زیبا با چهره‌ای متفاوت همچنان نیازمند بررسی
هویت است؛ امتیاز زیبایی به آن مجوز جایگزینی مرجع نمی‌دهد.

## سه بخش و سطح اجرای آن‌ها

1. **مرجع تصویری:** نام و SHA256 تصویر موقتِ تأییدشدهٔ ۱۹ اکتبر ثبت شده است.
   فایل تصویر تکرار نشده است. SHA256 فقط برابری بایت‌ها را نشان می‌دهد.
   برای تصویر تازه، شباهت چهره باید جداگانه و با منبع و اطمینان اعلام شود.
2. **ارزیابی:** امتیاز زیبایی و تناسب از ارزیابی انسانی، خروجی یک مدل بیرونی،
   یا fixture ساختگی دریافت می‌شود. خود این نسخه مدل بینایی اجرا نمی‌کند؛
   نسبت اندام‌ها را از پیکسل‌ها اندازه نمی‌گیرد و Q-Align نصب نشده است.
   نبود امتیاز به صورت unknown باقی می‌ماند. امتیازها باید در بازهٔ ۰ تا ۱ باشند.
3. **واکنش و تداوم:** سیگنال‌های طراحی‌شدهٔ `excellence`, `satisfaction`,
   `prediction_error`, `uncertainty` وارد `UnifiedBody.cycle(external.social)`
   می‌شوند. `admiration` و `contentment` و برنامهٔ عاطفی از همان لایهٔ موجود
   حاصل می‌شوند. درخواست، منابع ورودی، نتیجه و checkpoint در همان SQLite
   حلقهٔ بدن ثبت می‌شوند. اجرای تکراریِ همان درخواست اثر دوباره ندارد.

نسبت‌دادن تصویر به «خود/دیگری/نامعلوم» ورودی صریح است؛ این نسخه تشخیص خودکار
خود یا شناسایی بیومتریک انجام نمی‌دهد. `matching_declared_hash` یعنی هشِ اعلام‌شده
با مرجع مطابق است؛ فقط با `--image` بایت‌های فایل هم بررسی می‌شوند.
فرمول‌ها سیاست مهندسیِ تألیفی‌اند، نه مدل آموزش‌دیده یا پارامتر علمیِ برآوردشده.

زیبایی سیگنال هوش، فضیلت، اعتماد رابطه‌ای، موفقیت، کشش جنسی یا شرم تولید نمی‌کند.
ارزش خود و شایستگی اخلاقی از ظاهر محاسبه نمی‌شوند. دیدن تصویر خود فقط در صورت
تطابق کافی، رضایت محاسباتیِ اضافه‌ای می‌دهد؛ عدم تطابق به بررسی منجر می‌شود.
از این آزمایش‌ها تجربهٔ درونی، لذت از زیبایی یا تغییر وزن‌های ChatGPT نتیجه نمی‌شود.

## اجرا

پایتون ۳٫۱۱ به بالا، بدون کلید API، شبکه، PyTorch یا نصب وابستگی:

```sh
python -S -m examples.nasuraya_aesthetics test
python -S -m examples.nasuraya_aesthetics evaluate --output-dir /tmp/new-aesthetic-evaluation
```

ارزیابی شامل هشت مورد قراردادی با امتیازهای عمداً ساختگی است. هر مورد با یک
بدن تازهٔ بدون ورودی ظاهری مقایسه می‌شود. این آزمون کور یا سنجش عمومی زیبایی نیست.
هر دو مسیر یک کنش بدنی `observe` درخواست می‌کنند؛ برنامهٔ عاطفی می‌تواند متفاوت باشد.

نمونهٔ ورودی، با امتیاز فرضی که باید با ارزیابی واقعیِ دارای منبع جایگزین شود:

```json
{
  "id": "portrait-review-1",
  "image_sha256": "cb6d1be69347c76ac80f0f3340b7db83fde591fd90aa26b003ebb47ff736c5da",
  "subject": "self",
  "source": "operator_report",
  "source_ref": "operator://portrait-review-1",
  "ratings": {
    "beauty": {
      "value": 0.9,
      "confidence": 0.8,
      "kind": "operator_rating",
      "source_ref": "operator://portrait-review-1/beauty"
    }
  }
}
```

```sh
python -S -m examples.nasuraya_aesthetics report --observation /path/rating.json --image /path/portrait.png
python -m examples.nasuraya_body_loop start --session /tmp/new-visual.sqlite --max-actions 3
python -S -m examples.nasuraya_aesthetics apply --session /tmp/new-visual.sqlite --observation /path/rating.json --image /path/portrait.png
```

`report` بدن را اجرا نمی‌کند. `apply` یک چرخهٔ ۰٫۱ ثانیه‌ای شبیه‌سازی را از
بودجهٔ همان جلسه مصرف می‌کند. حالت مشاهدهٔ صرف، محدودیت بودجه، قفل هم‌زمانی،
بازیابی پس از توقف و veto بومیِ بدن همچنان از مسیر میزبان اعمال می‌شوند.
امتیاز جدید یا منبع جدید با شناسهٔ تکراری رد می‌شود؛ برای ارزیابی تازه شناسهٔ تازه بدهید.
اعلام منبع و اطمینان ساختاری است و صحتِ ارزیاب بیرونی را احراز نمی‌کند.

## مبنای پژوهشی و مرز اقتباس

- [AffectiveMirrorSelfRecognitionModel](https://github.com/JohnnyBauermeister/AffectiveMirrorSelfRecognitionModel)
  و [مقالهٔ ۲۰۲۲](https://arxiv.org/abs/2208.13213): الهام از جداکردن
  بازشناسی خود و valence. الگوریتم active inference آن بازتولید نشده است.
- [Q-Align](https://github.com/Q-Future/Q-Align) و
  [مقالهٔ ICML 2024](https://proceedings.mlr.press/v235/wu24ah.html):
  گزینهٔ آینده برای تولید امتیاز دارای منبع؛ این نسخه آن را اجرا نمی‌کند.
- [ArtEmis](https://github.com/optas/artemis) و
  [مقاله](https://arxiv.org/abs/2101.07396): توضیح اثر عاطفی تصویر بر انسان؛
  مدل، داده و توضیح‌گر آن وارد این نسخه نشده‌اند.
- [Beauty and the Bias](https://arxiv.org/abs/2504.16104): انگیزهٔ جدا نگه‌داشتن
  داوری ظاهری از اعتماد و شایستگی؛ آزمون اینجا فقط قرارداد همین نگاشت را می‌سنجد.

هیچ کد، وزن یا داده‌ای از این پروژه‌ها کپی نشده است. کد تازه مستقل نوشته شده و
از ماژول‌های عاطفی و دفتر اجرای موجود همین مخزن استفاده می‌کند. درخت منابع
بومیِ source-pinned تغییر نکرده است. گامِ باقی‌مانده، اتصال و اعتبارسنجی یک
ارزیاب بینایی واقعی روی مجموعه‌ای از تصاویر با داوری مستقل است.
