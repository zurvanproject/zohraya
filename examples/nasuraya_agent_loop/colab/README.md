# اجرای تعاملی در Colab

`Nasuraya_Colab_Live_Test.ipynb` کد نسخهٔ آزموده‌شدهٔ `7cda92a` را داخل خود دارد.
این فایل را در https://colab.research.google.com/ از File → Upload notebook باز کنید
و سلول‌ها را به ترتیب اجرا کنید. CPU کافی است؛ ZIP جدا یا دسترسی نوشتن GitHub لازم نیست.

سلول‌ها کد را با hash بررسی می‌کنند، وابستگی‌ها را در پوشهٔ اختصاصی نصب می‌کنند،
۴۲ آزمون و اجرای ساختگی را انجام می‌دهند و سپس ورودی مخفی کلید و یک اجرای
محدود API را فراهم می‌کنند. مدل پیش‌فرض مطابق quickstart رسمی است؛ دسترسی حساب
به آن هنوز بررسی نشده. فراخوانی API هزینهٔ مستقل از Colab دارد؛ سقف دلاری در
این نمونه پیاده‌سازی نشده است.

شواهد در `validation.json` ثبت شده‌اند: صحت schema دفترچه، اجرای snapshot
تعبیه‌شده، مسیر کلید خالی، بسته‌بندی گزارش و ثبت خطای احراز هویت با SDK واقعی
روی transport درون‌حافظه‌ای. هیچ کلید واقعی یا استنتاج زندهٔ مدل در بررسی استفاده نشد.
رابط Colab و ایجاد ماشین ابری در حساب کاربر هنوز آزموده یا انجام نشده‌اند.

Colab ماشین موقتِ تعاملی فراهم می‌کند؛ گزارش را پس از اجرا دانلود کنید.
این دفترچه برای فرایند دائمی پس‌زمینه تنظیم نشده است و هستهٔ تصمیم‌گیری، مدل خود
یا شبیه‌ساز بدن را وارد یا تغییر نمی‌دهد.

- https://developers.openai.com/api/docs/guides/agents-api/overview/
